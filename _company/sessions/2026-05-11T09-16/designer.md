# 📘 [필독] 브랜드 아이덴티티와 시스템 디자인 통합 가이드

## 🎯 목표: 일관성 있는 경험 제공 (Consistent Experience Delivery)
본 가이드는 우리의 비즈니스 메시지(브랜드 아이덴티티)가 사용자 인터페이스(시스템 디자인)를 거치면서 희석되지 않고, 일관되고 신뢰감 있는 경험을 제공하도록 돕는 것을 목표로 합니다.

---

## 💡 1. 브랜드 아이덴티티 (Brand Identity) 재정립

| 요소 | 정의 | 디자인 적용 가이드라인 |
| :--- | :--- | :--- |
| **핵심 가치** | 신뢰성, 혁신, 사용자 중심의 명료함 | 모든 요소는 군더더기 없이 명확해야 하며, 기술적 신뢰감을 전달해야 함. |
| **톤 앤 매너** | 전문적이고, 차분하며, 미래지향적 | 과도한 장식이나 현란한 색상 사용을 지양합니다. |
| **주요 메시지** | "가장 신뢰할 수 있는 AI 기반의 솔루션" | 사용자에게 안정감과 확신을 심어주는 시각적 요소를 강조합니다. |

## 🎨 2. 시스템 디자인 요소와 브랜드 매핑

| 디자인 요소 | 브랜드 매핑 (연결점) | 구체적 적용 가이드라인 |
| :--- | :--- | :--- |
| **색상 팔레트** | **메인 컬러 (신뢰):** 딥 블루 계열 (Primary) | 배경, 주요 CTA 버튼에 사용. 깊이감과 전문성을 부여합니다. |
| | **보조 컬러 (혁신):** 밝은 민트/청록 계열 (Accent) | 강조 포인트, 성공/주의 알림에 사용. 미래 지향적인 느낌을 추가합니다. |
| | **배경/텍스트:** 화이트/다크 그레이 | 가독성을 최우선으로 합니다. (WCAG 준수) |
| **타이포그래피** | **가독성:** 산세리프 계열 (예: Pretendard, Noto Sans) | 본문은 크고 명료하게. 헤드라인은 무게감을 주어 구조를 명확히 합니다. |
| **아이콘 및 일러스트** | **단순함:** 라인 기반 (Outline) | 복잡한 3D나 그림자 효과는 지양하고, 간결한 형태로 개념을 전달합니다. |

## 🛠️ 3. 핵심 컴포넌트별 적용 예시 (Component Usage)

### 3.1. CTA 버튼 (Call-to-Action)
*   **❌ (위반):** 과도한 그라데이션, 팝업 효과
*   **✅ (준수):** 딥 블루 배경에 흰색 텍스트. 마우스 오버 시 민트 계열로 미세하게 밝아지는 효과만 사용.
*   **원칙:** 사용자가 '무엇을 해야 하는지'를 명확하게 지시합니다.

### 3.2. 에러 메시지/경고창
*   **브랜드 연관성:** 에러 메시지라도 브랜드의 신뢰도를 잃어서는 안 됩니다.
*   **적용:** 경고(Warning) 시, 단순히 빨간색을 사용하기보다, **'사용자 경험을 개선하기 위한 조치'**라는 톤으로 접근하여, 문제 해결에 초점을 맞춥니다.

### 3.3. 레이아웃 (Layout)
*   **원칙:** 충분한 여백(Whitespace)을 확보합니다.
*   **효과:** 여백은 시각적 혼란을 줄이고, 콘텐츠의 중요도를 높여 '차분하고 명료한' 브랜드 이미지를 강화합니다.

## ⚖️ 4. 검토 체크리스트 (Self-Checklist)

새로운 화면이나 컴포넌트를 추가할 때, 다음 질문들을 스스로에게 던져보세요.

1.  **[일관성]** 이 디자인 요소는 기존의 다른 화면에서도 동일하게 사용되는가?
2.  **[명료성]** 이 디자인은 사용자에게 오직 하나의 행동(Next Action)만 요구하는가?
3.  **[브랜드 적합성]** 이 색상과 톤이 우리의 핵심 가치(신뢰성, 혁신)를 뒷받침하는가?
4.  **[단순함]** 꼭 필요한 것이 아닌 요소(불필요한 그림자, 애니메이션)는 제거할 수 있는가?
