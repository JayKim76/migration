# 🌐 디자인 시스템 V2.0: 통합 브랜드 가이드라인

**목표:** 웹사이트, 소셜 미디어, 마케팅 자료 전반에 걸쳐 일관되고 전문적인 사용자 경험(UX)을 제공하는 표준화된 디자인 시스템 구축.

**핵심 원칙:** 
1. **일관성 (Consistency):** 모든 접점에서 통일된 톤앤매너 유지.
2. **접근성 (Accessibility):** 모든 사용자가 불편함 없이 콘텐츠에 접근 가능하도록 높은 명암비와 직관적인 구조 설계.
3. **유연성 (Flexibility):** 플랫폼별 제약(Aspect Ratio, Character Limit 등)을 고려하여 확장 가능한 컴포넌트 설계.

## 🎨 1. 디자인 토큰 (Design Tokens)

모든 디자인 요소는 이 토큰을 기반으로 정의되어야 합니다.

| 토큰명 | 정의 (Value) | 용도 | 비고 |
| :--- | :--- | :--- | :--- |
| `--color-primary` | `#0056b3` | 핵심 액션 버튼, 강조 요소 | 브랜드의 신뢰성 상징 |
| `--color-secondary` | `#f4f4f9` | 배경색, 카드 배경 | 주 색상 대비를 위한 보조 색상 |
| `--color-text-dark` | `#212529` | 본문 텍스트 | 높은 가독성 확보 |
| `--color-accent-success` | `#28a745` | 성공/긍정적 피드백 |
| `--spacing-md` | `16px` | 표준 간격 (Padding, Margin) | 4px 기반 그리드 시스템 준수 |
| `--font-family-main` | 'Inter', sans-serif | 메인 타이포그래피 | 웹 환경에 최적화된 가독성 높은 폰트 |

## 🖼️ 2. 컴포넌트 라이브러리 (Component Library)

### A. 버튼 컴포넌트 (`Button`)

* **[Web Standard]:** `Padding: 16px 32px` / `Border-radius: 8px` / `Hover: --color-primary` (약간 어둡게)
* **[Mobile Standard]:** `Padding: 12px 24px` / `Border-radius: 6px`
* **규칙:** 사용자가 상호작용할 수 있는 모든 곳에 버튼 컴포넌트를 사용해야 합니다.

### B. 카드 컴포넌트 (`Card`)

* **구조:** 그림자(Shadow) → 내부 콘텐츠 영역(Padding) → 콘텐츠(Text/Image)
* **활용:** 정보 묶음, 기능 소개, 상품 리스트 등 구조적 분리가 필요할 때 사용.
* **주의:** 카드 간 간격은 반드시 `--spacing-md`를 준수할 것.

### C. 네비게이션 (`Navigation`)

* **Desktop:** 햄버거 메뉴 대신, 주요 카테고리 5개 이내의 텍스트 링크를 고정(Sticky) 할 것.
* **Mobile:** 햄버거 메뉴(Hamburger Menu)를 사용하며, 메뉴 클릭 시 풀스크린 오버레이(Full-screen Overlay) 형태로 펼쳐질 것.

## 📱 3. 플랫폼 가이드라인 (Platform Adaptability)

| 플랫폼 | 최적 가로세로 비율 | 사용 지침 | 필수 점검 사항 |
| :--- | :--- | :--- | :--- |
| **웹 (Desktop)** | 16:9 이상 | 그리드 시스템(12 Column Grid) 기반으로 설계. | 폰트 크기(Desktop Base Font Size)와 간격(Spacing)의 일관성. |
| **모바일 (Mobile)** | 9:16 (Portrait) | 터치 영역(Touch Target) 최소 크기 44px 확보. | 텍스트가 잘리는 현상(Truncation) 방지. |
| **SNS (Instagram/X)** | 1:1 또는 4:5 | 비주얼 콘텐츠에 초점을 맞추고, 브랜드 로고를 항상 배치. | 캡션(Caption)에 브랜드 해시태그 자동 삽입 기능 고려. |

### 💡 주요 변경 사항 및 적용 가이드

1. **토큰화:** 모든 색상, 간격, 폰트 크기를 변수(토큰)로 정의하여, 향후 브랜드 색상 변경 시 시스템 전체에 일괄 적용 가능하게 했습니다.
2. **반응형 최적화:** 각 플랫폼별 최적 비율과 사용 지침을 명시하여, 디자이너와 개발자가 크로스-디바이스 이슈를 사전에 방지할 수 있도록 했습니다.
3. **명확한 컴포넌트 규칙:** 각 컴포넌트(Button, Card 등)에 구체적인 크기 및 사용 규칙을 정의하여 '디자인 의사결정의 기준점' 역할을 하도록 했습니다.
```
