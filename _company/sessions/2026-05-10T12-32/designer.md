# 📐 [V2.0] AI-First 콘텐츠 비주얼 시스템 (Thumbnail & Branding System) 설계
**목표:** 'Live Mode'에서 대량으로 생산되는 다양한 형식의 콘텐츠(롱폼 영상, 숏폼 릴스, 블로그 아티클)에 적용 가능한 **통일되고 확장 가능한 디자인 시스템**을 구축합니다. 단순히 예쁜 썸네일이 아닌, 클릭률(CTR)과 브랜드 신뢰도를 동시에 높이는 **모듈형 프레임워크**를 제시합니다.

## 1. 🎨 핵심 디자인 원칙 (The Core Principles)
| 원칙 | 내용 | 적용 이유 |
| :--- | :--- | :--- |
| **명료성 (Clarity)** | 모든 썸네일은 3초 안에 주제와 가치를 명확히 전달해야 합니다. 복잡한 이미지 사용 금지. | 시청자의 스크롤링 속도와 경쟁 환경을 고려한 최우선 요소. |
| **기술적 신뢰도 (Authority)** | 다크 모드 기반의 세련되고 전문적인 톤을 유지하여, '데이터시스'의 기술 컨설팅 전문성을 강조합니다. | AI/데이터 분야의 타겟 청중에게 필수적인 요소. |
| **모듈성 (Modularity)** | 하나의 시스템 내에서 폰트, 컬러, 레이아웃이 재사용되어 모든 콘텐츠에 통일성을 부여합니다. | 대량 생산되는 콘텐츠의 비주얼 피로도(Visual Fatigue)를 방지합니다. |

## 2. 🎨 디자인 시스템 상세 정의

### 2.1. 컬러 팔레트 (Color Palette)
| 이름 | Hex Code | 역할 | 적용 영역 |
| :--- | :--- | :--- | :--- |
| **Primary Dark (배경)** | `#121212` | 메인 배경색. 전문적이고 깊은 느낌 제공. | 썸네일/비주얼의 주 배경색. |
| **Accent Blue (강조)** | `#007AFF` | 핵심 정보, CTA, AI의 빛을 상징. | 중요 키워드 하이라이트, 화살표, 하단 바. |
| **Secondary Blue (데이터)** | `#34C759` | 긍정적 변화, '성공/자동화'를 시각화. | 결과 수치, 성공 지표, 긍정적 전환점 표시. |
| **Warning Red (경고)** | `#FF3B30` | 문제점, 위험 요소를 지적할 때 사용. | '문제점', '실패 사례', '주의' 문구에 사용. |
| **Text White (텍스트)** | `#F2F2F7` | 기본 텍스트 색상. 높은 가독성 확보. | 모든 주요 헤드라인 및 본문 텍스트. |

### 2.2. 타이포그래피 (Typography)
*   **폰트 세트:** Pretendard (가장 높은 가독성을 제공하는 시스템 폰트)
*   **헤드라인 (H1):** Pretendard Bold (24~36pt)
    *   **특징:** 가장 핵심 메시지를 간결하게, 최대 7단어 이내로 압축합니다.
*   **서브 헤드라인 (H2):** Pretendard SemiBold (18~24pt)
    *   **특징:** 영상의 구체적인 주제나 장점을 설명합니다.
*   **본문/데이터 (Body):** Pretendard Regular (12~16pt)
    *   **특징:** 수치, 출처, 작은 설명 텍스트에 사용합니다.
