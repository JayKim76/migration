### 🎨 웹사이트 리디자인 프로젝트 - 인스타그램 콘텐츠 비주얼 시스템 가이드 (최적 컨셉 기반)

**[1. 프로젝트 개요 및 목표]**

*   **프로젝트:** 데이터시스 웹사이트 리디자인 및 인스타그램 홍보 캠페인
*   **목표:** 데이터시스의 전문성과 신뢰성(Zero-Risk)을 전달하며, AI 자동화 솔루션 컨설팅의 가치를 시각적으로 극대화한다.
*   **최적 컨셉 (선정):** [전문성 강조형: 데이터 기반의 구조화된 정보 전달]
    *   *선정 이유:* 데이터시스의 핵심 가치인 '데이터 기반 컨설팅'을 가장 명확하게 보여주며, 복잡한 AI 개념을 청중이 쉽게 이해하도록 구조화된 흐름을 제공한다.

**[2. 비주얼 시스템 (Visual System)]**

| 요소 | 사양 | 설명 |
| :--- | :--- | :--- |
| **톤앤매너** | 모던, 전문적, 신뢰감, 구조적 | 어두운 배경(Dark Mode)을 기반으로 핵심 정보에만 밝은 액센트를 주어 몰입도를 높임. |
| **주요 색상 팔레트** | **Primary:** `#003366` (네이비/신뢰) | 메인 배경, 제목, 핵심 구조물에 사용. |
| | **Secondary:** `#1A4C8E` (딥 블루) | 보조 배경, 분리선, 부제목에 사용. |
| | **Accent:** `#4CAF50` (성장/성공 그린) | CTA 버튼, 성공 지표, 핵심 키워드 강조. |
| | **Warning/Error:** `#FF6B6B` (경고/실패) | 문제점, 주의 사항, 부정적 시나리오 설명 시 사용. |
| **타이포그래피** | **Headline:** Pretendard Bold (가독성, 힘) | 제목, 핵심 문구. (크기 비율: H1: 32pt, H2: 24pt) |
| | **Body:** Pretendard Regular (균형, 안정감) | 본문 내용, 설명 텍스트. (크기 비율: 16pt) |

**[3. 템플릿 가이드라인 (Template Guide)]**

**A. 썸네일 (Thumbnail - 1:1 비율, 1080x1080px 기준)**

*   **레이아웃:** 3분할 구조 (좌/중/우)
*   **배경:** 딥 블루(`Secondary`)를 은은하게 그라데이션 처리.
*   **핵심 구성 요소:**
    1.  **좌측 (문제 제기):** 문제점/Pain Point를 경고 컬러(`Warning/Error`)로 강조한 짧은 문구. (예: "여전히 수동으로 작업하십니까?")
    2.  **중앙 (해결책/솔루션):** 가장 크고 굵은 Pretendard Bold를 사용. 핵심 메시지(예: "AI 자동화 솔루션 구축").
    3.  **우측 (결과/가치):** 긍정적인 결과 지표(숫자)와 성공 컬러(`Accent`)를 조합. (예: "시간 80% 절약", "효율 극대화")
*   **필수 요소:** 데이터시스 로고 (우측 하단, 투명도 60%)

**B. 인스타그램 캐러셀 포스트 (Carousel Post - 1:1 비율, 1080x1080px 기준)**

*   **목표:** 하나의 주제를 3~5개의 슬라이드로 풀어 설명하는 논리적 흐름 구현.
*   **슬라이드 1 (표지):** 썸네일과 유사하게 구성하되, '오늘의 주제'를 명확히 기재. (제목, 부제목, 데이터시스 로고)
*   **슬라이드 2~4 (본문):**
    *   **레이아웃:** 텍스트와 다이어그램/아이콘의 6:4 비율 유지.
    *   **흐름:** 문제 정의 $\rightarrow$ 원인 분석 (데이터 기반) $\rightarrow$ 해결책 제시 (솔루션).
    *   **시각화:** 텍스트 블록 사이에 굵은 실선(`Primary`)과 화살표 아이콘을 배치하여 정보의 흐름을 강제적으로 유도.
*   **슬라이드 N (CTA):** 반드시 다음 행동을 유도하는 명확한 CTA 섹션 배치. (예: "프로젝트 문의하기", "프로필 링크 클릭")
