### 🎨 1. 핵심 디자인 요소 정의 (Brand Style Guide)

| 요소 | 정의/규칙 | 사용 예시 (규칙) |
| :--- | :--- | :--- |
| **컬러 팔레트** | **Primary (메인):** `#004D99` (신뢰, 전문성) | 제목, 핵심 CTA 버튼 배경 |
| | **Secondary (보조):** `#FF9900` (활력, 주목) | 하이라이트, 강조 포인트, 경고 메시지 |
| | **Neutral (기본):** `#333333` (가독성) | 본문 텍스트, 배경 요소 |
| **타이포그래피** | **헤드라인:** Pretendard Bold (28pt ~ 48pt) | 콘텐츠의 주제와 중요도를 직관적으로 전달 |
| | **본문:** Pretendard Regular (14pt ~ 16pt) | 긴 설명, 정보 전달의 핵심 요소 |
| **아이콘 스타일** | **Line-art (선형):** 획 두께 1.5px, 끝은 둥글게 처리 | 기능적 요소(Step, Feature)에 활용. 너무 화려한 그림체 지양. |

### 📝 2. 콘텐츠 구조 및 톤앤매너 가이드라인 (Tone & Manner)

| 영역 | 가이드라인 | 예시 문구 (Before/After) |
| :--- | :--- | :--- |
| **톤앤매너** | **전문적, 신뢰감, 친절함.** (과장된 감성적 표현 지양) | **(X)** "와우! 저희 서비스가 여러분의 인생을 바꿔줄 거예요!" **(O)** "데이터 기반의 분석을 통해 최적의 의사결정을 지원합니다." |
| **제목 구조** | **[핵심 키워드] + [얻게 되는 가치]** 구조를 따를 것. | **(예시)** '데이터 분석'을 통해 '비즈니스 리스크'를 줄이는 방법 |
| **CTA 문구** | **명령형, 명확성 극대화.** (추상적 표현 금지) | **(X)** "더 알아보세요." **(O)** "무료 데모 신청하기" / "자세히 살펴보기" |

### 🖼️ 3. 레이아웃 및 시각화 규칙 (Layout & Visualization)

*   **정보 계층 구조:** 가장 중요한 정보(핵심 가치)는 항상 상단 1/3에 배치하고, 시각적 대비(색상/크기)를 극대화한다.
*   **이미지 활용:** 추상적인 개념 설명 시에는 반드시 **인포그래픽**이나 **다이어그램**을 사용하여 시각화한다. (단순 사진 나열 지양)
*   **데이터 시각화:** 차트 사용 시, Primary 색상을 데이터의 '변화 추이'에 할당하고, Secondary 색상을 '비교 대상'에 할당한다.
