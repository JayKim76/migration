## 📄 1. 시스템 개요 및 목표
본 문서는 데이터시스(Datasys)의 모든 콘텐츠 제작물(블로그, 카드 뉴스, 발표 자료, 웹 UI 등)에 적용될 표준 비주얼 가이드라인을 제공합니다. 목표는 **'기술적 신뢰도와 사용자 친화적 이해도를 극대화'**하는 것입니다.

---

## 🎨 2. 컬러 시스템 (Color Palette)
데이터시스는 '신뢰'와 '혁신'을 핵심 가치로 합니다. 따라서 차분한 딥 네이비와 대비되는 활력 있는 블루를 중심으로 조합합니다.

| 이름 | 역할 | HEX 코드 | CMYK (인쇄용 참고) | 사용 예시 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary** (주조색) | 브랜드 정체성, 메인 CTA | `#1A237E` (Deep Navy) | C=70, M=75, Y=35, K=75 | 헤더 배경, 로고, 주요 섹션 배경 |
| **Secondary** (보조색) | 강조, 성공, 긍정적 액션 | `#42A5F5` (Sky Blue) | C=70, M=55, Y=0, K=0 | 버튼 배경, 그래프의 긍정적 요소 |
| **Accent** (액센트) | 경고, 실패, 데이터 흐름 | `#FF1744` (Error Red) | C=0, M=90, Y=90, K=0 | 에러 메시지, 주의 단계, 핵심 지표 강조 |
| **Background** | 기본 배경색 | `#FFFFFF` | C=0, M=0, Y=0, K=0 | 본문 배경 |
| **Text/Dark** | 기본 텍스트 색상 | `#37474F` (Dark Slate Gray) | C=70, M=60, Y=50, K=60 | 본문 텍스트, 제목 텍스트 |
| **Utility/Gray** | 구분선, 비활성화 요소 | `#E0E0E0` | C=10, M=5, Y=5, K=10 | 구분선(Divider), 배경 하이라이트 |

## ✒️ 3. 타이포그래피 시스템 (Typography System)
**선정 폰트:**
1.  **제목 및 헤더 (Headings):** Pretendard (Bold/SemiBold) - (가독성과 현대적 느낌)
2.  **본문 및 코드 (Body/Code):** Pretendard (Regular) 또는 Consolas (코드 블록 전용) - (기술적 명료성)

| 요소 | 크기 (px) | 폰트 굵기 | 줄 간격 (Line Height) | 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **H1** (메인 제목) | 48px | Bold | 1.2 | 블로그 포스트의 핵심 주제 |
| **H2** (섹션 제목) | 32px | SemiBold | 1.4 | 섹션 구분, 목차의 대분류 |
| **H3** (소제목) | 24px | SemiBold | 1.5 | 하위 내용 제목, 카드뉴스 주제 |
| **Body Text** (본문) | 16px | Regular | 1.6 | 일반 설명 문구, 블로그 본문 |
| **Caption** (캡션) | 14px | Regular | 1.5 | 그래프 설명, 이미지 출처 |
| **Code Block** | 14px | Regular | 1.4 | 코드 스니펫, 명령어 예시 |

## 🧩 4. 컴포넌트 라이브러리 (Component Library)

### 4.1. 버튼 (Button)
*   **Primary Button:** 배경: `#42A5F5` (Secondary), 텍스트: `#FFFFFF`, Corner Radius: 8px.
*   **Secondary Button:** 배경: `transparent`, 텍스트: `#1A237E` (Primary), Border: 1px solid `#1A237E`.
*   **Disabled Button:** 배경: `#E0E0E0` (Utility), 텍스트: `#BDBDBD`.

### 4.2. 데이터 시각화 (Data Visualization)
*   **차트 기본 원칙:** 데이터 흐름을 명확히 하기 위해 '흐름(Flow)'의 방향성을 강조합니다.
*   **라인 그래프:** 주 데이터는 `#42A5F5` 사용. 추세 변화 또는 예측 데이터는 `#1A237E` 사용.
*   **파이 차트:** 비율이 가장 높은 항목에만 Primary/Secondary를 사용하고, 나머지는 Utility Gray로 처리하여 복잡도를 낮춥니다.
*   **표 (Table):** 헤더는 Primary 배경, 구분선은 Utility Gray를 사용하여 명료도를 높입니다.

### 4.3. CTA 및 강조 요소 (Call-to-Action & Emphasis)
*   **인용구 (Blockquote):** 왼쪽 여백에 Primary 색상의 세로선(2px)을 삽입하여 시각적 분리 효과를 극대화합니다.
*   **강조 텍스트:** 굵게 처리하거나, 핵심 키워드에만 배경색을 은은하게 적용하여 독자의 시선을 유도합니다.

2.  **톤앤매너 확정:** 기술적이고 전문적인 톤을 유지하되, 친근함을 잃지 않는 균형점을 찾습니다.
3.  **컴포넌트 라이브러리 구축:** 버튼, 카드, 섹션 등 재사용 가능한 UI 컴포넌트의 디자인 규칙을 정립합니다.
