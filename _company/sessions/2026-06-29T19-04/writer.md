# ✍️ Writer — 수집된 데이터를 바탕으로 간결하면서도 효과적인 카피라이팅을 진행하고, 인스타그램 포스트의 캡션을 작성하여 고객에게 호기심을 부추겨주세요.

✍️ Writer: 작업 시작합니다.

인스타그램 포스트 캡션을 작성하여 고객의 호기심을 유발하도록 카피라이팅을 진행하겠습니다. 수집된 데이터를 바탕으로 간결하면서도 매력적인 문장으로 표현할 것입니다.

##### **캡션 예시**

---

**릴스 (Reels) - AI 트렌드 소개**
```
🎥 새로운 미래, 지금 바로 확인하세요! 🌐 #AI #MachineLearning #TechTrends

💡 오늘의 릴스에서는 최신 인공지능 기술이 어떻게 우리의 일상을 변화시키는지를 보여드립니다. 흥미로운 정보와 함께 함께 미래를 설계해보세요!
```

**스토리 (Stories) - 고객 피드백 요청**
```
📅 오늘의 스토리는 당신에게 주어진 질문에 답하는 시간입니다! 📊

🤔 '데이터 시대에서 가장 중요한 기술 트렌드는 무엇인가요?' 우리에게 이 질문에 대한 답변을 알려주세요! #QandA #AskMeAnything
```

---

이제 각 캡션 예시를 바탕으로 인스타그램 에이전트에게 전달하여 고객 참여를 유도하도록 합니다.

```markdown
# 작업 분배:

- 📷 **인스타그램 에이전트**: 
  - **릴스 캡션 작성**:
    - 작업 이름: sessions/2026-06-29T15_45_instagram_reels_caption.md
    - 메모리 참조: #AI_Trends, #Engagement_Highlight

  - **스토리 캡션 작성**:
    - 작업 이름: sessions/2026-06-29T15_45_instagram_story_caption.md
    - 메모리 참조: #Customer_Feedback_Questions, #Interactive_Storyline

이제 각 에이전트에게 위의 지시를 분배하고 작업을 시작하도록 안내합니다.
```
