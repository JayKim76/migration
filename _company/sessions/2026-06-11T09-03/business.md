💼 현빈: PayPal 매출 데이터 수집을 위한 준비 작업이 필요합니다. 먼저 사용자가 API 키를 설정하도록 안내하겠습니다.

1. 사용자에게 `PayPal Developer Dashboard`에서 `CLIENT_ID`와 `SECRET`을 발급받아 `/Volumes/temp/AI/company/_company/_agents/business/tools/paypal_revenue.json` 파일에 입력하라고 안내합니다.
2. 이후 실제 데이터 수집 작업을 진행할 수 있게 될 것입니다.

먼저 사용자에게 API 키 설정 방침을 알려드리겠습니다:
```
💰 PayPal 매출 분석을 위해 아래 과정을 따르세요:

1. PayPal Developer Dashboard (https://developer.paypal.com/dashboard/applications) 접속
2. 본인의 앱(Client ID + Secret) 정보를 찾아서 클립보드에 복사합니다.
3. 설정 파일 (`/Volumes/temp/AI/company/_company/_agents/business/tools/paypal_revenue.json`)을 열어 API 키들을 입력합니다.

이제 데이터 분석을 시작할 수 있습니다.
```
