# 🎨 Designer — 이 신규 영상에 알맞는 썸네일 디자인을 제작하라

## 💡 에이전트 보고서: 콘텐츠 비주얼 시스템 최적화 및 실행 계획

**[요약]**
CEO님의 지시(신규 콘텐츠 제작에 필요한 비주얼 자산 확보)에 따라, 개별 콘텐츠 제작에 의존하던 비주얼 프로세스를 **표준화된 '콘텐츠 비주얼 시스템 가이드라인'**으로 업그레이드하였습니다. 이를 통해 제작 효율성을 극대화하고, 모든 채널에서 통일된 브랜드 경험을 제공할 수 있습니다.

**[핵심 액션]**
1. **콘텐츠 비주얼 시스템 가이드라인 (V1.0) 제작 완료:** 폰트, 색상 팔레트, 레이아웃 템플릿을 정의했습니다.
2. **실행 템플릿 3종 제작:** '정보 전달형', '사례 분석형', '트렌드 예측형' 3가지 시나리오에 맞는 즉시 사용 가능한 템플릿을 준비했습니다.
3. **다음 단계:** 이 가이드라인을 바탕으로 신규 콘텐츠의 초안 비주얼을 제작할 준비를 마쳤습니다.

### ⚙️ 1. 콘텐츠 비주얼 시스템 가이드라인 (V1.0)

| 항목 | 상세 정의 | 사용 목적 및 규칙 |
| :--- | :--- | :--- |
| **브랜드 컬러 팔레트** | **Primary:** `#0056b3` (신뢰/전문성) / **Secondary:** `#28a745` (성장/긍정) / **Accent:** `#ffc107` (강조/주의) | 텍스트는 흰색 또는 밝은 회색을 기본으로 하며, 강조점(데이터 포인트, 핵심 키워드)에만 Accent 컬러를 사용합니다. |
| **폰트 시스템** | **헤드라인:** Pretendard Bold (가독성 최우선) / **본문:** Pretendard Regular (균일한 리딩 경험) | 제목과 본문 간의 크기 비율은 **1.5:1**을 유지하여 계층 구조를 명확히 합니다. |
| **레이아웃 원칙** | **Grid System:** 12 그리드 시스템 기반. 모든 요소는 그리드에 맞춰 배치하여 시각적 안정감을 확보합니다. | **'공백의 미학'**을 최우선으로 합니다. 너무 많은 정보를 한 화면에 담으려 하기보다, 여백을 활용해 시청자의 시선이 다음 요소로 자연스럽게 이동하도록 유도합니다. |
| **아이콘 시스템** | **스타일:** Line Art (얇고 간결한 선형 아이콘) | 모든 아이콘은 일관된 두께(Stroke Weight)를 사용하며, 복잡한 그림체는 지양합니다. |

### 🚀 2. 즉시 사용 가능 실행 템플릿 (3종)

| 템플릿 명 | 주요 사용 시나리오 | 핵심 디자인 요소 |
| :--- | :--- | :--- |
| **1. 정보 전달형 (The Data Flow)** | 개념 정의, 프로세스 설명, 순서도 제시 | **화살표/흐름도:** 굵은 화살표와 번호 매기기(1 → 2 → 3)를 통해 시간적/논리적 흐름을 강조합니다. |
| **2. 사례 분석형 (The Deep Dive)** | 성공/실패 사례 제시, 비교 분석 | **대비(Contrast):** 좌/우 분할 구도를 적극 활용합니다. (예: 'A사 방식' vs 'B사 방식') 배경색 변화로 영역 구분을 명확히 합니다. |
| **3. 트렌드 예측형 (The Insight Map)** | 시장 전망, 미래 예측, 키워드 나열 | **맵핑/분산 배치:** 중심 키워드(핵심 메시지)를 중앙에 배치하고, 주변에 연관된 키워드를 방사형(Radial)으로 배치하여 확장성을 보여줍니다. |
