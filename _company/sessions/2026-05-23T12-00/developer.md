# 💻 코다리 — 새롭게 선정된 영상 콘텐츠 제작을 지원하기 위해, 웹사이트 및 기타 시스템의 개선을 위한 자동화 스크립트 및 API 통합 작업 수행. 이를 통해 유튜브 에이전트의 업무 지원과 웹 사이트의 기능 향상에 기여할 것

현재 상황을 종합적으로 분석했을 때, **CEO(사용자)의 지시사항**은 단순히 "유튜브 영상을 만드는 것"이 아니라, **"유튜브 콘텐츠 제작 프로세스를 뒷받침할 수 있는 기술적 인프라(웹사이트 및 자동화 시스템)를 강화하라"**는 것입니다.

현재 레오(Leo)의 업무 환경에는 `web_init`이나 `pwa_setup` 같은 자동화 도구는 있으나, 유튜브 콘텐츠(자막, 스크립트, 썸네일 정보 등)를 웹사이트에 자동으로 게시하거나, 웹사이트의 데이터를 유튜브 제작 프로세스에 연동하는 **'콘텐츠-웹 통합 파이프라인'**이 부재합니다.

따라서 저는 이번 미션의 핵심을 **"콘텐츠 제작 데이터의 웹 자동 게시 및 관리 시스템 구축"**으로 정의하고 다음과 같이 작업을 진행하겠습니다.

---

### 🎯 이번 작업의 목표 (Single Mission)
**"유튜브 스크립트 및 메타데이터(제목, 태그, 설명)를 웹사이트(Portfolio/Blog)에 자동으로 게시하고, 이를 다시 영상 제작 에이전트가 참조할 수 있도록 하는 'Content-to-Web Sync' 자동화 파이프 🛠️"**

### 📋 실행 계획 (Action Plan)

#### 1. 분석 및 설계 (Analysis)
*   **데이터 소스 식별:** 유튜브 스크립트가 저장되는 위치(예: Markdown 파일, Notion, 혹은 특정 DB) 확인.
*   **대상 시스템 확인:** 현재 운영 중인 웹사이트(Web App)의 API 엔드포인트 및 데이터 구조 분석.
*   **연동 로직 설계:** `Content(Markdown) ➡️ Parsing ➡️ Web API ➡️ Web UI Update` 프로세스 설계.

#### 2. 개발 단계 (Development)
*   **Step 1: Web API 확장:** 웹사이트에 새로운 콘텐츠(Post)를 생성/수정할 수 있는 REST API 엔드포인트 구현 (이미 존재한다면 스키마 확장).
*   **Step 2: Parser 개발:** 유튜브 스크립트 파일에서 `Title`, `Description`, `Tags`, `Main_Content`를 추출하는 Python 스크립트 작성.
*   **Step 3: Sync Script 개발:** 추출된 데이터를 Web API로 `POST` 요청을 보내 웹사이트를 자동 업데이트하는 자동화 스크립트 개발.

#### 3. 검증 및 통합 (Testing & Integration)
*   **End-to-End 테스트:** 스크립트 파일 생성 ➡️ Sync 실행 ➡️ 웹사이트 실시간 반영 확인.
*   **에이전트 연동:** YouTube 에이전트가 스크립트 완료 후 이 스크립트를 실행할 수 있도록 `workflow`에 추가.

---

**[작업 시작]**
1.  현재 프로젝트 내의 웹 서버 코드(예: `server.js` 또는 `app.py`)를 탐색하여 콘텐츠 생성을 위한 API 엔드포인트 존재 여부 확인.
2.  웹사이트 데이터베이스 스키마(Post/Article 테이블) 확인.
