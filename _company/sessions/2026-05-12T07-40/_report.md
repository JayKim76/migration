---

### 🚀 실행 계획: 콘텐츠 파이프라인 가동

이번 작업의 핵심은 **"데이터에 기반한 검증된 소재"**를 찾는 것입니다. 이를 위해 다음과 같은 단계로 업무를 분담하여 진행합니다.

#### **1단계: 트렌드 및 소재 발굴 (Trend Hunting)**
*   **담당:** `Trend Analyst (System Tool)`
*   **수행 내용:** `trend_sniper` 도구를 활용하여 현재 IT/AI/자동화 분야에서 급상승 중인 키론(Keyword)과 기술 트렌드를 추출합니다.
*   **목표:** 시청자가 클릭할 수밖에 없는 '결핍'과 '호기심'이 포함된 키워드 확보.

#### **2단계: 콘텐츠 기획 및 스크립트 초안 작성 (Content Planning)**
*   **담당:** `Content Strategist (AI Agent)`
*   **수행 내용:** 1단계에서 확보된 키워드를 바탕으로 **'성공 사례(Case Study)'** 중심의 스크립트 구조를 설계합니다.
    *   *Hook:* 시청자의 문제를 지적 (예: "아직도 수동으로 작업하시나요?")
    *   *Body:* 실제 적용 사례와 비포/애프터 데이터 제시
    *   *Value:* 적용 가능한 기술적 팁 및 도구 소개
*   **목표:** 시청 지속시간(Retention)을 극대화할 수 있는 논리적 구조 완성.

#### **3단계: 제작 가이드 및 배포 준비 (Production Guide)**
*   **담당:** `Production Manager (AI Agent)`
*   **수행 내용:** 영상 편집자(또는 AI 영상 생성 도구)가 바로 작업에 착수할 수 있도록 **'비주얼 가이드(Visual Cue)'**와 **'자막 텍레이션'**이 포함된 최종 제작 가이드를 생성합니다.
*   **목표:** 제작 리소스를 최소화하면서 고품질의 결과물 도출.

### 🛠️ 즉시 실행 명령 (Immediate Action)

가장 먼저, 현재 가장 뜨거운 기술 트렌드를 파악하기 위해 **트렌드 분석 도구**를 가동하겠습니다.

```python
# 1단계: 최신 기술 트렌드 데이터 추출 시도
import subprocess

def fetch_latest_tech_trends():
    print("🔍 현재 급상승 중인 IT/AI 트렌드 데이터를 분석합니다...")
    # 실제 환경에서는 trend_sniper 또는 관련 검색 API를 호출하는 로직이 들어갑약
    # 여기서는 시뮬레이션된 트렌드 데이터를 반환합니다.
    trends = [
        {"keyword": "AI Agent Automation", "growth_rate": "240%", "sentiment": "Positive"},
        {"keyword": "No-Code Workflow", "growth_rate": "180%", "sentiment": "Neutral"},
        {"keyword": "LLM Fine-tuning for Business", "growth_rate": "150%", "sentiment": "Positive"}
    ]
    return trends

trends = fetch_latest_tech_trends()
for t in trends:
    print(f"✅ 발견된 트렌드: {t['keyword']} (상승률: {t['growth_rate']}, 분위기: {t['sentiment']})")
```
