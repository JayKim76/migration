## 📑 Part 1. 업무 자동화 체크리스트 (Automation Readiness Checklist)
*새로운 업무를 마주했을 때, 이 프로세스에 따라 '자동화 가능성'을 판단하십시오.*

### 1단계: 업무 식별 (Identification)
- [ ] **반복성:** 이 업무가 주기적으로(일간/주간/월간) 발생하는가?
- [ ] **규칙성:** 업무 수행 과정에 명확한 'If-Then' 로직(규칙)이 존재하는가?
- [ ] **데이터화:** 업무의 입력값(Input)과 출력값(Output)이 디지털 데이터(텍text, Excel, Email 등)로 존재하는가?

### 2단계: 자동화 적합성 평가 (Feasibility)
- [ ] **예측 가능성:** 업무의 결과가 정해진 규칙 내에서 예측 가능한가?
- [ ] **의사결정 복잡도:** 판단에 필요한 변수가 너무 많거나 주관적인 직관이 핵심인가? (낮을수록 좋음)
- [ ] **기술적 구현 가능성:** 현재 보유한 툴(Zapier, Make, Python, GPT 등)로 구현 가능한 범위인가?

### 3단계: 자동화 설계 (Workflow Design)
- [ ] **Trigger 설정:** 어떤 이벤트가 발생했을 때 자동화가 시작될 것인가? (예: 이메일 수신, 구글 시트 행 추가)
- [ ] **Action 정의:** 트리거 이후 수행될 단계별 액션은 무엇인가? (예: 데이터 추출 -> 요약 -> 알림 발송)
- [ ] **Error Handling:** 오류 발생 시(데이터 누락, 형식 오류 등) 어떻게 알림을 받고 대응할 것인가?

## 🛠️ Part 2. AI 프롬프트 엔지니어링 템플릿 (Universal Prompt Framework)
*AI에게 단순한 질문을 하지 마십시오. 아래의 **'C-T-C-F' 구조**를 사용하여 명확한 지시를 내리십시오.*

### 🏗️ [C-T-C-F] 프레임워크 구조

| 요소 | 명칭 | 설명 | 예시 |
| :--- | :--- | :--- | :--- *Context (맥락)* | 업무의 배경, 역할(Persona), 대상(Audience)을 설정 | "당신은 10년차 전문 마케터입니다. 신제품 런칭을 앞두고 있습니다." |
| | **Task (과업)** | AI가 수행해야 할 구체적인 행동을 동사 중심으로 기술 | "블로그 포스팅용 초안을 작성하세요." |
| | **Constraint (제약사항)** | 반드시 지켜야 할 규칙, 금지 사항, 톤앤매너 | "전문적이되 친근한 말투를 사용하고, 3문장 이내로 요약하세요." |
| | **Format (출력 형식)** | 결과물의 구조, 언어, 파일 형식, 데이터 구조 | "표(Table) 형식으로 정리하고, Markdown 문법을 사용하세요." |

### 📝 바로 쓰는 프롬프트 복사용 템플릿
```text
# Role: [여기에 AI의 역할을 입력하세요. 예: 데이터 분석 전문가]

# Context: [현재 상황과 배경을 설명하세요. 예: 우리 회사는 이번 분기 매출이 10% 감소했습니다.]

# Task: [수행할 작업을 구체적으로 입력하세요. 예: 감소 원인을 분석하고 대응 전략 3가지를 제안하세요.]

# Constraints:
- [제약사항 1: 예: 예산 범위 내에서 제안할 것]
- [제약사항 2: 예: 전문 용어 사용을 지양할 것]
- [제약사항 3: 예: 한국어로 작성할 것]

# Output Format:
- [형식 1: 예: 불렛포인트로 정리]
- [형식 2: 예: 실행 계획을 포함한 표 형태]
```

## 💡 Part 3. 생산성 향상을 위한 Tip
1. **Iterative Prompting (반복적 프롬프팅):** 한 번에 완벽한 답을 얻으려 하지 마세요. 결과물을 보고 "이 부분은 더 구체적으로", "이 부분은 생략해줘"라고 추가 지시를 내리는 것이 핵심입니다.
2. **Few-Shot Prompting (예시 제공):** AI에게 원하는 결과물의 '예시'를 하나만 보여줘도 품질이 비약적으로 상승합니다.
3. **Chain of Thought (단계적 사고):** "단계별로 생각해서 설명해줘"라는 문구를 추가하면 복잡한 논리 문제 해결 능력이 향상됩니다.

---
*Created by AI Automation Strategy Team*
```
