# 📋 작업 브리프

**원 명령:** 개발 데이타베이스는 postgreSQL을 사용하도록 수정하고 다시 개발 진행해.

## 요약
개발 데이터베이스를 PostgreSQL로 전환하고, 이에 따른 환경 설정 변경 및 개발 프로세스 재개

## 분배
- **💻 Developer**: 개발 환경 설정(config) 파일에서 데이터베이스 엔진을 PostgreSQL로 변경하고, PostgreSQL 연결성 및 기존 쿼리 호환성을 검증한 후 개발 프로세스를 재개할 것
- **📱 Secretary**: 데이터베이스 전환에 따른 환경 설정 변경 사항을 작업 로그에 기록하고, PostgreSQL 기반의 개발 진행 상황을 모니터링하여 보고할 것
