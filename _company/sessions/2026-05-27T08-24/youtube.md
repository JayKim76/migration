# 📺 레오 — 지난 24시간 동안 업로드한 최신 영상에 대해 상세한 분석을 수행하고, 이를 바탕으로 다음 콘텐츠 전략을 수립하라.

현재 시스템의 상태와 CEO의 지시 사항을 종합하여, **최근 업로드된 영상의 성과를 분석하고 이를 바탕으로 다음 콘텐츠 전략을 수립하기 위한 실행 계획**을 수립하였습니다.

현재 YouTube 채널의 성과를 정밀하게 진단하기 위해서는 단순한 조회수 확인을 넘어, **`my_videos`** 도구를 통한 구체적인 메트릭(시청 지속 시간, 클릭률 등) 확인이 필수적입니다.

---

### 🚀 실행 계획: 최신 영상 성과 분석 및 차기 전략 수로 수립

#### **1단계: 최신 영상 데이터 추출 및 정밀 진단**
*   **목표:** 최근 업로드된 영상의 핵심 성과 지표(KPI)를 확보하여 '성공 요인'과 '이탈 지점'을 파악합니다.
*   **실행 도구:** `my_videos` (YouTube API 연동)
*   **분석 항목:**
    *   **CTR (Click-Through Rate):** 썸네일과 제목이 타겟 시청자에게 얼마나 매력적이었는가?
    *   **Average View Duration (AVD):** 영상의 어느 구간에서 시청자 이탈이 발생했는가? (편집 호흡, 정보 밀도 분석)
    *   **Relative Performance:** 채널 평균 영상 대비 성과 비교.

#### **2단계: 콘텐츠 전략 수립 (Action Plan)**
*   **목표:** 1단계의 분석 결과를 바탕으로 **'확장(Scale-up)'** 또는 **'수정(Pivot)'** 전략을 결정합니다.
*   **시나리오 A (성과 우수 시):** 해당 영상의 주제를 심화(Deep-dive)하거나, 유사한 포맷의 시리즈물 기획.
*   **시나리오 B (성과 저조 시):** 썸네일/제목 교체(A/B Test), 영상 도입부(Hook) 개선, 또는 주제의 시장성 재검토.

---

### 📅 업무 할당 (Task Allocation)

| 담당 에이전트 | 할당 작업 (Task) | 기대 결과물 (Deliverable) |
| :--- | :--- | :--- |
| **YouTube API Agent** | `my_videos` 호출을 통한 최신 영상 메트릭(CTR, AVD, Views) 수집 | 영상별 성과 데이터 시트 |
| **Content Strategist** | 수집된 데이터를 바탕으로 한 **'콘텐츠 개선 및 확장 전략 보고서'** 작성 | 차기 영상 기획안 (Hook, Topic, Thumbnail 전략 포함) |

---

### 🛠️ 즉시 실행 명령 (Immediate Action)

먼저 최신 영상의 데이터를 가져오기 위해 아래 명령을 실행합니다.

```python
# YouTube 채널의 최신 영상 메트릭을 확인하기 위한 실행 명령
print(my_videos())
```

**[알림]** 위 명령 실행 후 결과가 나오면, 즉시 **Content Strategist** 에이전트가 분석에 착수하여 CEO께 보고드릴 차기 전략안을 제출하겠습니다.
