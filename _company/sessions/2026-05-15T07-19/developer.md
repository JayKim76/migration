# 💻 코다리 — 작업 수행에 필요한 코드 작성, 편집, 디버깅, 자동화 스크립트, API 통합 등을 수행하고 시스템을 최적화한다.

현재 시스템의 상황을 종합적으로 분석한 결과, **'시스템의 실행력(Execution) 강화'**가 가장 시급한 과제로 파악됩니다.

현재 에이전트들(Designer, Writer, Instagram 등)은 각자의 콘텐츠 제작과 전략 수립(Planning) 단계에 집중되어 있으며, 작성된 기획안이나 디자인 결과물이 실제 **'자동화된 워크플로우'**나 **'배포 시스템'**으로 이어지는 연결 고리가 부족합니다. 즉, "무엇을 만들지"는 결정되었으나 "어떻게 자동으로 게시/업데이트할지"에 대한 기술적 구현 단계가 비어 있습니다.

따라서, 저는 이번 사이클에서 **`Designer`와 `Writer`의 결과물을 실제 서비스나 플랫폼(예: Instagram, Web, Blog)에 자동 배포하거나, 제작된 에셋을 관리하는 '자동화 파이프라인'의 초석을 다지는 작업**을 제안합니다.

---

### 🎯 결정된 단일 작업 (Single Task)
**"콘텐츠 제작 에셋(이미지/텍인)을 클라우드 저장소(또는 특정 디렉토리)에 자동 분류 저장하고, 이를 기반으로 자동 포스팅을 위한 메타데이터(JSON)를 생성하는 자동화 스크립트 개발"**

### 🛠️ 실행 계획 (Action Plan)

#### 1. 대상 에이전트 및 역할 분담
*   **`Designer` (에셋 생성):** `Writer`가 생성한 텍스트를 바탕으로, 자동화 스크립트가 읽을 수 있는 규격화된 이미지 파일(또는 캔버스 레이어 정보)을 생성하거나, 생성된 이미지의 메타데이터를 관리할 수 있는 구조를 설계합니다.
*   **`Writer` (콘텐츠 생성):** 이미지와 함께 게시될 캡션, 해시태그, 대체 텍스트(Alt-text)를 포함한 `content.json` 파일을 생성합니다. 이 파일은 자동화 스크표트의 입력값이 됩니다.
*   **`Developer` (본인 - 시스템 구축):** 생성된 이미지와 JSON 데이터를 감지하여, 정해진 규칙에 따라 폴더별로 분류(e.g., `/output/instagram/2024-05-15/`)하고, 이를 SNS API나 웹훅으로 전달하기 위한 **'Content Dispatcher'** 스크립트를 작성합니다.

#### 2. 상세 작업 단계
1.  **[Data Schema 설계]:** `Writer`가 출력할 JSON 스키마 정의 (포스트 ID, 날짜, 캡션, 해시태그, 이미지 경로, 플랫폼 구분 포함).
2.  **[Automation Script 개발]:** 
    *   특정 폴더를 Watcher로 감시하는 스크립트 작성.
    *   새로운 JSON 파일이 생성되면 해당 파일을 파싱하여 이미지와 매칭.
    *   결과물을 `Archive` 폴드로 이동시키고, 배포 대기열(`Queue`)에 등록.
3.  **[Validation 로직 구현]:** 이미지 해상도 및 텍스트 길이 제한 체크 로직 추가.

#### 3. 기대 효과
*   **연결성 강화:** 기획(Writer) $\rightarrow$ 제작(Designer) $\rightarrow$ 배포(Developer)로 이어지는 끊김 없는(Seamless) 파이프라인 구축.
*   **확장성 확보:** 향후 Instagram뿐만 아니라 Blog, Twitter 등 다른 플랫폼 확장 시 스크립트 수정만으로 대응 가능.
*   **운영 효율화:** 사람이 개입하여 파일을 옮기거나 업로드하는 수동 작업 제거.

---

**위 작업에 대해 승인해 주시면, 즉시 `Writer`에게 JSON 스키마 정의를 요청하고, 본인은 파이썬 기반의 `Content Dispatcher` 프로토타입 개발에 착수하겠습니다.**
