### 🛠️ 상세 실행 로드맵 (Step-by-Step)

#### **Step 1: 데이터 스키마 및 API 설계 (Developer)**
*   **Action:** 기존 `videos` 테이블에 `category`와 `tags` 필드를 추가하는 마이그레이션 스크립트 작성.
*   **API:** `POST /api/v1/videos/upload` 엔드포인트에 `subject_id`와 `metadata`를 수용할 수 있도록 확장.

#### **Step 2: AI 기반 자동 태깅 프로토타입 (Developer + AI)**
*   **Action:** 업로드된 영상의 제목이나 설명을 분석하여 미리 정의된 `category_id`를 매칭하는 간단한 Python 스크립트(NLP 기반) 개발.
*   **Goal:** 사용자가 주제를 수동으로 입력하지 않아도 시스템이 자동으로 분류를 제안하도록 함.

#### **Step 3: 업로드 워크플로우 자동화 (DevOps)**
*   **Action:** 영상 파일이 특정 저장소(예: AWS S3, Local Storage)에 업로드되는 것을 감지(Event-driven)하여, 위에서 만든 자동 태깅 스크립트를 실행하고 DB를 업데이트하는 파이프라인 구축.

#### **Step 4: 관리자 대시보드 연동 (UI/UX)**
*   **Action:** 관리자가 주제별로 영상을 필터링하여 조회할 수 있는 API 연동 및 목록 뷰(List View) 업데이트.
