## 🌐 웹사이트 정보 구조(IA) 및 UX 설계 제안

클라이언트의 요구사항을 반영하고, AI 기반 솔루션의 전문성을 극대화하기 위해 다음과 같은 5단계의 정보 구조(IA)와 사용자 경험(UX) 흐름을 제안합니다.

### 1. 사이트맵 (Site Map) 구조

전체 웹사이트의 메뉴 구조는 '정보의 계층성'을 명확히 하여 사용자가 길을 잃지 않도록 설계합니다.

*   **메인 페이지 (Home):** 브랜드 메시지 전달 및 주요 서비스로의 빠른 유도 (Entry Point)
*   **회사 소개 (About Us):** 신뢰 구축 (Trust Building)
    *   우리의 가치/비전
    *   팀 소개 (전문가 프로필)
    *   인증 및 파트너십
*   **서비스/솔루션 (Solutions):** 핵심 기능 설명 (Core Value)
    *   솔루션 1: [주요 서비스명] (상세 기능, 도입 사례)
    *   솔루션 2: [보조 서비스명] (기술적 우위점)
    *   솔루션 3: [컨설팅/맞춤형] (커스터마이징 옵션)
*   **포트폴리오/사례 연구 (Portfolio):** 실질적 증명 (Proof Point)
    *   산업별 성공 사례 (업종 필터링 기능 필수)
    *   케이스 스터디 상세 (문제점 $\rightarrow$ 우리의 해결책 $\rightarrow$ 결과)
*   **문의하기 (Contact):** 액션 유도 (Call to Action)
    *   문의 폼 (필수 입력 항목 최적화)
    *   오시는 길/전화번호

### 2. 핵심 사용자 플로우 (User Flow) 설계

가장 중요한 두 가지 플로우를 정의하여 사용자가 웹사이트에 들어온 후 목표를 달성하는 과정을 설계합니다.

#### 🎯 플로우 A: 신규 고객의 인지 $\rightarrow$ 문의 전환 (Conversion Path)
1.  **진입 (Home):** 헤드라인을 통해 '문제 인식' 유도 $\rightarrow$ **핵심 가치(AI 전문성)** 시각화.
2.  **탐색 (Solutions):** 관심 분야의 솔루션 카드 클릭 $\rightarrow$ **상세 기능** 및 차별점 확인.
3.  **신뢰 확보 (Portfolio):** 유사 산업의 성공 사례 확인 $\rightarrow$ **"우리 회사도 이 정도는 할 수 있겠다"**는 확신 획득.
4.  **전환 (Contact):** 상세한 문의를 위해 '문의하기' 클릭 $\rightarrow$ 문의 폼 작성.

#### 🎯 플로우 B: 파트너사/투자자의 정보 탐색 (Exploration Path)
1.  **진입 (About Us):** 회사의 비전과 역량에 집중하여 '신뢰' 확인.
2.  **정보 탐색 (Team/Partners):** 핵심 인재 또는 파트너사 목록 검토.
3.  **상세 정보 확인:** 특정 전문가 프로필 클릭 $\rightarrow$ **경력 및 연구 성과** 확인.
4.  **후속 조치 (Contact):** 협업 가능성에 대한 문의 $\rightarrow$ 담당자 직접 연락 요청.

### 3. 페이지별 와이어프레임 (Wireframe) 구조 제안

각 페이지에 들어갈 콘텐츠의 배치(레이아웃)를 정의합니다.

| 페이지 | 섹션 구성 (Top to Bottom) | UX/UI 핵심 요소 |
| :--- | :--- | :--- |
| **Home** | **Hero Section** (강력한 헤드라인 + CTA) $\rightarrow$ **Pain Point 제시** (사용자 공감 유도) $\rightarrow$ **Solution Overview** (3가지 핵심 서비스 아이콘) $\rightarrow$ **Trust Section** (주요 고객사 로고 슬라이더) $\rightarrow$ **CTA** (가장 중요한 행동 유도). | **Sticky Navigation:** 스크롤 시 주요 메뉴 강조. **반응형:** 모바일에서 정보 밀도가 높지 않도록 분리. |
| **Solutions** | **개요 섹션** (우리가 해결할 수 있는 문제 정의) $\rightarrow$ **솔루션별 탭/카드** (클릭 시 상세 정보 펼쳐짐) $\rightarrow$ **기술적 차별점** (AI 아키텍처 다이어그램 등 시각화). | **대화형 요소:** 탭 전환 시 부드러운 애니메이션 적용. **도식화:** 텍스트 나열보다 플로우 차트 사용. |
| **Portfolio** | **필터링 바** (산업별, 문제 유형별 필터링) $\rightarrow$ **카드 목록** (프로젝트 제목, 클라이언트 로고, 핵심 키워드) $\rightarrow$ **상세 케이스 스터디 템플릿**. | **필터링:** 사용자가 원하는 정보를 즉시 찾을 수 있도록 구현. **가독성:** 성공 스토리의 구조(Before/After)를 명확히 분리. |
| **Contact** | **CTA 재강조** (가장 눈에 띄게 배치) $\rightarrow$ **문의 폼** (최소한의 질문만 요구) $\rightarrow$ **연락처 정보** (지도 및 업무 시간). | **폼 유효성 검사:** 오류 발생 시 즉각적인 피드백 제공. **신뢰성:** 문의 후 예상 회신 시간 명시. |

### 4. 시각적/톤앤매너 제안 (Tone & Manner)

*   **컬러 팔레트:** 신뢰를 상징하는 **딥 네이비(Deep Navy)**를 메인 컬러로 사용하고, AI 기술의 첨단 이미지를 나타내는 **밝은 블루(Electric Blue)**를 포인트 컬러로 활용합니다.
*   **타이포그래피:** 가독성이 높고 모던한 산세리프 계열의 폰트(예: Pretendard, Noto Sans)를 사용하여 기술적인 전문성을 강조합니다.
*   **이미지 사용:** 추상적인 이미지보다는 **데이터 시각화, 프로세스 플로우 차트, 실제 작업 환경**을 보여주는 고품질의 일러스트레이션이나 사진을 우선적으로 사용합니다.

### 5. 향후 액션 플랜 (Next Steps)

1.  **피드백 요청:** 위에서 제안된 사이트맵과 와이어프레임 구조에 대한 피드백을 요청드립니다.
2.  **와이어프레임 확정:** 구조가 확정되면, 각 페이지의 상세 와이어프레임을 확정하고, 이를 기반으로 UI 디자인 단계로 진입합니다.
3.  **콘텐츠 준비:** 각 페이지에 들어갈 최종 텍스트(카피라이팅)와 로고, 성공 사례의 상세 데이터가 준비되어야 디자인 작업 속도를 높일 수 있습니다.
