### 📅 라이브 스트림 개요

### 🛠️ 에이전트별 역할 분담 (Task Allocation)

이번 라이브의 핵심은 **"에이전트들이 실제로 일하는 모습을 실시간으로 보여주는 것"**입니다.

#### 1. 🎬 YouTube/Streaming Setup Agent (Technical Support)
*   **역할:** 방송 송출 환경 구축 및 기술적 안정성 확보
*   **주요 과업:**
    *   OBS(Open Broadcaster Software) 장면 구성 (CEO 화면 + 에이전트 대시보드 + 실시간 채팅창).
    *   스트리밍 네트워크 안정성 체크 및 비상 시 백업 송출 경로 확보.
    *   라이브 스트림용 오디오/비디오 퀄리티 최적화.

#### 2. 📊 Data & Dashboard Agent (Visualizing the Business)
*   **역할:** 실시간 비즈니스 지표(KPI) 시각화
*   **주요 과업:**
    *   **실시간 대시보드 구축:** 현재 진행 중인 프로젝트 상태, 유튜브 조회수, 매출 추이, 에이전트들의 작업 완료율 등을 시각화된 그래프로 준비.
    *   **에이전트 작업 로그 출력:** 각 에이전트(YouTube, Twitter, Blog 등)가 현재 어떤 텍록을 처리하고 있는지 실시간 텍스트 스트림(Terminal 느낌) 준비.

#### 3. 📝 Script & Content Agent (Storytelling)
*   **역할:** 라이브 방송 흐름(큐시트) 작성 및 스크립트 가이드 제공
*   **주요 과업:**
    *   **큐시트(Cue Sheet) 작성:** 오프닝 $\rightarrow$ 에이전트 소개 $\rightarrow$ 실제 작업 시연 $\rightarrow$ Q&A $\rightarrow$ 클로징의 타임라인 구성.
    *   **에이전트 소개 스크립트:** 각 에이전트(YouTube Agent, Researcher Agent 등)의 역할과 성과를 설명할 핵심 키워드 정리.
    *   **Q&A 예상 질문 리스트:** 시청자들이 물어볼 법한 질문(비용, 기술적 구현 방법, 미래 전망 등)에 대한 답변 가이드 작성.

####  Capable of "Live Demo" Agent (The Star of the Show)
*   **역할:** 라이브 도중 실시간으로 명령을 받아 작업을 수행하는 모습 시연
*   **주요 과업:**
    *   CEO가 채팅창에 명령을 입력하면, 에이전트가 즉각적으로 뉴스 요약, 이미지 생성, 또는 블로그 포스팅 초안을 작성하는 과정을 화면에 공유.
