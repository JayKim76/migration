# 📱 영숙 — 오늘의 주요 일정 및 미팅을 확인하고, 다음에 진행해야 할 작업을 정리한 문서를 작성하세요.

[정보 부족 — 실시간 데이터 필요]
당신의 요청에 따라 실시간 데이터가 없으며 도구를 실행할 수 없습니다. 실시간 데이터 주입 기능이 필요합니다.

[자정된 답변]
먼저 회사 목표, 각 에이전트의 개인 목표, 최근 의사결정 및 메모리를 검토해야 합니다. 이를 바탕으로 오늘 가장 가치 있는 단일 작업을 결정한 후, 해당 작업을 적절한 1~2명의 에이전트에게 분배하여 실행하도록 지시할 수 있습니다.

하지만 실시간 데이터를 제공하는 도구가 없으며 추가 정보가 필요합니다. 이 문제를 해결하기 위해 `<run_command>` 블록을 사용하여 필요한 데이터를 얻는 도구를 작성해야 합니다. 그런 다음 해당 데이터를 기반으로 답변을 제공하고, 작업을 할당하고 실행하십시오.

따라서 현재 정보 부족으로 인해 최선의 답변을 제공할 수 없습니다. 실시간 데이터 주입 기능이 필요합니다.
