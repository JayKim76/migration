# 🎨 Designer — 분석 결과를 바탕으로 새로운 썸네일 디자인과 브랜딩 비주얼을 개발합니다.

## 💡 전략적 분석 및 실행 계획: 비주얼 콘텐츠 시스템 구축

**[요약]**
현재 팀은 콘텐츠 주제와 트렌드를 분석하는 단계(전략/기획)를 성공적으로 수행했습니다. 다음 단계는 이 분석된 아이디어를 실제 시청자의 시선을 사로잡는 **일관된 시각적 시스템(Visual System)**으로 전환하는 것입니다.

단순히 주제별로 이미지를 제작하는 것을 넘어, **"어떤 콘텐츠가든 일관된 톤앤매너로 제작할 수 있는 가이드라인"**을 만드는 것이 핵심 목표입니다.

---

### 🎯 핵심 목표: [AI-Powered Content System] 구축

**목표:** 어떤 주제의 콘텐츠가 들어와도, 브랜드 아이덴티티가 훼손되지 않는 템플릿 기반의 시각적 가이드라인을 확립합니다.

**산출물:**
1.  **브랜드 컬러/폰트 가이드라인 (Style Guide):** 핵심 요소 정의
2.  **콘텐츠 템플릿 세트 (Template Set):** 유튜브 썸네일, 인포그래픽, 카드 뉴스 3종 확정
3.  **콘텐츠 제작 워크플로우 (Workflow):** 기획 → 디자인 → 검수 프로세스 정의

---

### 🛠️ 실행 단계 및 역할 분담

| 단계 | 세부 액션 플랜 | 주력 산출물 | 예상 소요 시간 | 담당 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 브랜드 자산 정의** | **A. 컬러 시스템 확정:** 메인 컬러(신뢰), 서브 컬러(강조), 배경 컬러(가독성) 3단계 정의. (AI/기술 느낌의 차가운 톤 지향) | **컬러 팔레트 (HEX Code)** | 1일 | 기획/디자인 리드 |
| | **B. 폰트 시스템 확정:** 제목용(강렬함), 본문용(가독성) 폰트 쌍 확정. | **폰트 가이드 (Weight & Hierarchy)** | 1일 | 디자인 리드 |
| **2. 핵심 템플릿 설계** | **A. 유튜브 썸네일 (가장 중요):** [제목/강조 이미지/브랜드 로고] 3분할 구도 확정. **(최우선순위)** | **썸네일 템플릿 (PSD/Figma)** | 2일 | 디자인 리드 |
| | **B. 인포그래픽/카드 뉴스:** 3단계(문제 제기 → 해결책 → 결론) 구조에 맞는 레이아웃 확정. | **카드 뉴스 템플릿 (PPT/Figma)** | 2일 | 디자인 리드 |
| **3. 검증 및 가이드 확립** | **A. 파일럿 테스트:** 확정된 템플릿에 분석된 주제(예: 'LLM의 작동 원리')를 임시 적용하여 3가지 버전 제작. | **최종 가이드라인 문서** | 1일 | 전체 팀 |
| | **B. 워크플로우 확정:** 기획자가 초안을 만들고, 디자이너가 템플릿에 넣어 완성하는 프로세스 매뉴얼 작성. | **제작 가이드라인 (매뉴얼)** | 1일 | 기획 리드 |

---

### 🔍 ✨ 즉시 적용 가능한 '프롬프트 개선점'

현재의 분석 결과(예: "AI의 트렌드")를 디자인으로 가져갈 때, 단순히 "AI가 멋있게 보이게 해주세요"라는 요청은 피해야 합니다. 아래와 같이 **구체적인 시각적 언어**를 사용해야 합니다.

| ❌ **(나쁜 요청)** | ✅ **(개선된 요청)** | **핵심 개선 포인트** |
| :--- | :--- | :--- |
| "AI 기술에 대한 멋진 썸네일 만들어 줘." | **"미래지향적이고 신뢰감 있는 톤으로, 메인 컬러(딥블루)를 중심으로, 그리드 기반의 레이아웃을 사용한 썸네일 템플릿을 만들어 줘."** | **구체적인 스타일(Tone), 색상, 구조(Grid)** 명시. |
| "정보가 많으니 깔끔하게 정리해 줘." | **"정보의 계층 구조를 명확히 하기 위해, 핵심 키워드에만 강조색(옐로우)을 사용하고, 텍스트 블록은 2줄 이하로 제한하는 인포그래픽 템플릿을 요청합니다."** | **시각적 계층 구조(Hierarchy)**를 지시. |
| "트렌드를 보여주는 이미지가 필요해." | **"추상적인 개념(트렌드)을 시각화하기 위해, 데이터 흐름을 나타내는 유기적인 라인 아트(Organic Line Art) 스타일의 아이콘 세트를 10개 제작해 줘."** | **원하는 시각적 메타포(Visual Metaphor)**를 지정. |

**결론:** 다음 주까지 **[브랜드 스타일 가이드 문서]**를 완성하고, 이를 기반으로 **[3종 템플릿 세트]**를 제작하는 데 집중하는 것이 가장 효율적입니다.
