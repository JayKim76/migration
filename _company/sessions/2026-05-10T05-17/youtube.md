### 🛠️ 실행 계획: 사전 검증 및 가동 준비

1.  **단계 1: 단독 실행 테스트 (`trend_sniper` 검증)**
    *   `trend_sniper`를 수동으로 실행하여 YouTube Data API 키의 유효성, 키워드 검색 결과 반환 여부, 그리고 로컬 LLM/API와의 연결 상태를 즉시 확인합니다.
    *   이 과정에서 에러 발생 시 즉시 `youtube_api_key` 및 `llm_config`를 수정합니다.

2.  **단계 2: 환경 무결성 체크**
    *   `youtube_api_key`가 현재 유효한지, 쿼리 제한(Quota)에 걸릴 위험은 없는지 체크합니다.
    *   `llm_connection`이 안정적인지 확인하여 자동화 프로세스 중 끊김 현상을 방지합니다.

3.  **단계 3: 오토 플래너(`auto_planner`) 정식 가동**
    *   검증 완료 후, 2시간 간격 스케줄링을 설정하여 `auto_planner`를 백그라운드에서 실행합니다.
