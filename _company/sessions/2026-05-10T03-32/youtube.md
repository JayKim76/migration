# 📺 레오 — 오토 플래너 도구 사용 시 각 시간대별로 생성되는 영상의 스크립트와 썸네일을 기획합니다.

현재 시스템 상태를 분석한 결과, `auto_planner`는 실행 준비가 되어 있으나, **`youtube_api_key`가 설정되지 않아** 실제 데이터를 가져오거나 분석을 시작할 수 없는 상태입니다. 또한, `youtube_api_key` 외에도 `youtube_client_secret` 등의 인증 정보가 누락되어 있어 API 호출 시 오류가 발생할 가능성이 높습니다.

따라서, 현재 단계에서 바로 스크립트를 작성하는 것은 무의미하며, **먼저 실행 환경을 구축하는 것이 최우선 과제**입니다.

### 📋 현재 상황 분석 및 실행 계획

1.  **문제점 (Blocker):**
    *   `youtube_api_key` 누락으로 인해 YouTube Data API를 통한 트렌드 데이터 수집 불가.
    *   `youtube_client_secret` 등 인증 정보 부재로 OAuth2 인증 프로세스 진행 불가.
    *   이로 인해 `auto_planner`가 참조할 '실제 트렌드 데이터'가 없는 상태임.

2.  **단기 실행 계획 (Action Plan):**
    *   **Step 1 (환경 구축):** 사용자에게 `youtube_api_key` 및 필요한 환경 변수 설정을 요청하거나, 테스트용 더미(Dummy) 키 설정을 제안합니다.
    *   **Step 2 (데이터 확보):** API 연결 성공 확인 후, `auto_planner`가 참조할 수 있는 최신 AI/Automation 관련 영상 메타데이터를 수집합니다.
    *   **Step 3 (기획 실행):** 수집된 데이터를 기반으로 시간대별(Morning/Afternoon/Evening) 콘텐츠 테마를 설정하고, 이에 맞는 스크립트 및 썸네일 컨셉을 생성합니다.

**[Option B] 더미 데이터 기반 프로토타입 생성 (속도 우선)**
