# 🎨 Designer — 분석 결과를 바탕으로 1인 기업의 브랜드 비주얼 및 디자인 전략을 고민하고, 시각적으로 매력적인 썸네일과 로고 등을 설계하여 회사 이미지 강화를 도모할 수 있도록 작업에 참여하세요.

## 🧠 [Task: 브랜드 아이덴티티 및 시각 디자인 가이드라인 제안]

**배경 분석:**
제공해주신 연구 자료를 바탕으로, 우리 브랜드가 지향해야 할 핵심 가치(AI 기반의 효율성, 첨단 기술력, 신뢰성)를 시각적으로 구현하는 것이 중요합니다. 단순히 기술을 나열하는 것을 넘어, **'기술을 통해 사용자의 성공을 돕는다'**는 인간 중심적 가치를 전달하는 것이 목표입니다.

**제안 목표:**
브랜드의 일관성을 확보하고, 잠재 고객에게 전문성과 신뢰를 주는 시각적 언어(Visual Language)를 정립합니다.

## 🎨 1. 브랜드 핵심 시각 요소 (Visual Identity System)

### 🔵 1.1. 브랜드 컬러 팔레트 (Color Palette)

| 컬러명 | HEX Code | CMYK | 역할 및 의미 | 사용처 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary Blue (핵심 신뢰)** | `#0056B3` | 100/70/0/10 | **신뢰, 전문성, 기술.** 브랜드의 메인 컬러로 사용. | 로고, 핵심 CTA 버튼, 헤드라인 강조. |
| **Secondary Teal (미래 지향)** | `#17A2B8` | 70/15/0/10 | **혁신, 성장, 차분함.** 기술적 깊이를 표현. | 보조 그래프, 섹션 구분선, 아이콘. |
| **Accent Green (성장/효율)** | `#28A745` | 80/0/90/0 | **성공, 긍정적 결과, 효율성.** 사용자가 얻는 가치 강조. | 성공 사례, 핵심 지표(KPI) 강조, CTA. |
| **Background Gray (배경/정돈)** | `#F8F9FA` | 0/0/0/0 | **깔끔함, 가독성.** 콘텐츠의 배경색으로 사용. | 배경, 여백. |
| **Text Black (가독성)** | `#343A40` | 70/60/50/70 | **가독성, 명확성.** 본문 텍스트에 사용. | 본문, 설명 텍스트. |

### 🔵 1.2. 타이포그래피 (Typography)

*   **메인 폰트 (제목/강조):** **Pretendard** 또는 **Spoqa Han Sans Neo**
    *   *선택 이유:* 현대적이고 간결하며, 디지털 환경에서 높은 가독성을 자랑합니다. 기술적인 느낌과 전문성을 동시에 전달합니다.
    *   *활용:* H1, H2, 섹션 제목.
*   **보조 폰트 (본문):** **Noto Sans KR**
    *   *선택 이유:* 범용성이 높고, 긴 텍스트를 읽을 때 눈의 피로도가 적어 콘텐츠의 몰입도를 높입니다.
    *   *활용:* 본문 설명, 리스트.

### 🔵 1.3. 로고 활용 가이드라인

*   **원칙:** 로고 주변에는 최소 1.5배 이상의 여백(Clear Space)을 확보하여 답답함을 없앱니다.
*   **사용 예시:**
    1.  **풀 컬러:** 가장 공식적인 자리 (헤더, 프레젠테이션 표지).
    2.  **단색(흑백):** 인쇄물, 팩스, 흑백 보고서 등 잉크 제약이 있는 경우. (메인 컬러의 90% 농도로 변환)

## ✨ 2. 콘텐츠 및 UI/UX 디자인 가이드라인

### 🔵 2.1. 레이아웃 및 그리드 시스템

*   **그리드:** 12컬럼 그리드 시스템을 표준으로 채택합니다. (웹사이트 및 리포트 표준)
*   **여백:** 콘텐츠 블록 간의 간격은 최소 40px 이상 확보하여 시각적 휴식 공간을 제공합니다. (여백은 곧 고급스러움입니다.)
*   **정보 계층 구조:** 가장 중요한 정보(핵심 가치, 결과)는 항상 가장 크게, 그리고 가장 밝은 색상(Accent Green)으로 배치합니다.

### 🔵 2.2. 아이콘 및 일러스트레이션 스타일

*   **스타일:** **라인(Line) 기반의 플랫(Flat) 디자인**을 지향합니다.
    *   *특징:* 단순하고 명료하며, 기술적이고 정제된 느낌을 줍니다.
*   **일관성:** 모든 아이콘은 동일한 두께(Stroke Weight)를 사용하며, 색상 코드는 Primary Blue 또는 Secondary Teal을 기본으로 합니다.
*   **추가 제안:** 추상적인 개념(AI, 연결, 데이터 흐름)은 **미니멀한 모션 그래픽**을 활용하여 설명하는 것이 효과적입니다. (예: 점들이 연결되며 데이터 흐름을 만드는 애니메이션)

### 🔵 2.3. 데이터 시각화 (Data Visualization)

*   **차트 선택:** 복잡한 3D 차트보다는 **간결한 2D 차트**를 우선 사용합니다.
*   **강조 포인트:** 데이터가 보여주는 **'성장'**이나 **'효율성'** 지점은 반드시 Accent Green으로 포인트를 주어 시선을 유도해야 합니다.
*   **레이블:** 축 레이블과 단위는 명확하게 표시하되, 불필요한 설명은 생략하여 '읽기 쉬운' 차트를 만드는 데 집중합니다.

## 🚀 3. 최종 점검 체크리스트 (Design QA Checklist)

| 항목 | 점검 내용 | 적합성 (O/X) | 비고 |
| :--- | :--- | :--- | :--- |
| **일관성** | 모든 섹션에서 지정된 컬러 팔레트와 폰트가 일관되게 사용되었는가? | | |
| **가독성** | 배경색과 텍스트색의 대비(Contrast Ratio)가 충분하여 읽기 편한가? | | |
| **여백 활용** | 내용이 밀집되어 보이지 않고, 충분한 '숨 쉴 공간'이 확보되었는가? | | |
| **톤 앤 매너** | 전반적인 분위기가 '첨단', '신뢰', '전문적'인 톤을 유지하는가? | | |
| **CTA 명확성** | 사용자가 다음 행동(버튼 클릭)을 해야 할 곳이 눈에 가장 먼저 들어오는가? | | |

이 가이드라인을 기반으로 디자인 시스템을 구축한다면, 우리 브랜드는 시장에서 **'신뢰할 수 있고, 미래를 선도하는 전문 기업'**이라는 강력한 인상을 구축할 수 있을 것입니다.
