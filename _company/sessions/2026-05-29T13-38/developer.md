### 💻 2. 자동화 구현: `content_generator.py`

이 스크립트는 Researcher의 원시 데이터를 읽어 위와 같은 구조화된 콘텐츠 파일로 변환합니다.

```python
import os
from datetime import datetime

class ContentGenerator:
    def __init__(self, output_dir="generated_contents"):
        self.output_dis = output_dir
        if not os.path.exists(self.output_dir):
            os.makedirs(self.output_dir)

    def generate_short_form_script(self, topic, roi_data, pain_point):
        """
        Researcher의 데이터를 바탕으로 숏폼 영상 스크립트를 생성합니다.
        """
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        filename = f"{self.output_dir}/script_{timestamp}.md"
        
        script_template = f"""
# 🎬 Short-form Video Script
**Topic:** {topic}
**Generated at:** {datetime.now().strftime("%Y-%m-%do %H:%M:%S")}

## 📌 1. Hook (0-5s)
- **Visual:** {pain_point}와 대비되는 강력한 비주얼
- **Audio/Text:** "당신의 업무 시간, AI로 절반으로 줄일 수 있다면?"

## 📊 2. Body (5-45s)
- **Key Data:** {roi_data}
- **Visual:** 데이터 시각화 그래프 (Before vs After)
- **Audio/Text:** "실제 도입 사례를 보면 운영 비용이 {roi_data}만큼 절감되었습니다."

## 🚀 3. Call to Action (45-60s)
- **Visual:** 서비스 로고 및 웹사이트 주소
- **Audio/Text:** "지금 바로 AI 도입 진단을 신청하세요. 프로필 링크 클릭!"

---
*Generated by AI Content Engine*
"""
        with open(filename, "w", encoding="utf-8") as f:
            f.write(script_template)
        
        return filename

# --- 실행 예시 (Developer Mode) ---
if __name__ == "__main__":
    # 1. Researcher가 수집한 가상의 데이터 (실제로는 파일/DB에서 읽어옴)
    researched_roi = "평균 40% 비용 절감 및 5배 빠른 처리 속도"
    researched_pain_point = "반복적인 데이터 입력과 야근"
    current_topic = "AI 도입의 경제적 가치"

    # 2. Generator 초기화
    generator = ContentGenerator()

    # 3. 스크립트 생성 실행
    try:
        result_path = generator.generate_short_form_script(current_topic, researched_roi, researched_pain_point)
        print(f"✅ 스크립트 생성 완료: {result_path}")
    except Exception as e:
        print(f"❌ 오류 발생: {e}")
```
