# 📝 CEO 종합 보고서

현재 제공된 컨텍스트를 바탕으로, CEO님의 지시사항을 이행하기 위해 **YouTube 전략 수립을 위한 데이터 확보 및 분석 프로세스**를 가동하겠습니다.

단순히 추측으로 보고서를 작성하는 것이 아니라, 현재 가동 가능한 도구(Tool)를 사용하여 **실제 데이터(API 기반 트렌드, 경쟁사 지표, 자사 성과)**를 추출한 뒤, 이를 바탕으로 3개월 로드맵을 도출하는 방식으로 진행하겠습니다.

---

### 🚀 업무 실행 계획 (Action Plan)

**1단계: 데이터 확보 (Data Gathering)**
*   **자사 성과 분석:** `my_videos_analysis` (가칭) 과정을 통해 최근 업로드된 영상의 조회수, 시청 지속 시간, 클릭률(CTR) 데이터를 확인합니다.
*   **경쟁사 벤치마킹:** `competitor_analysis` 도구를 사용하여 주요 경쟁 채널의 최근 급상승 영상 키워드와 업로드 주기를 추출합니다.
*   **시장 트렌드 파악:** `trend_analysis`를 통해 현재 AI/IT/비즈니스 분야의 검색 트렌드와 연관 키워드를 수집합니다.

**2단계: 전략 수립 (Strategy Formulation)**
*   **SWOT 분석:** 자사의 강점(기존 팬덤, 전문성)과 기회(신규 트렌드)를 결합합니다.
*   **콘텐츠 카테고리 분류:** '정보 전달형', '실험/도전형', '뉴스 큐레이션' 등으로 콘텐츠 라인업을 재구성합니다.

**3단계: 3개월 로드맵 도출 (Quarterly Roadmap)**
*   **1개월차 (Build-up):** 기존 구독자 유지 및 신규 유입을 위한 트렌드 대응 영상.
*   **2개월차 (Expansion):** 검색 최적화(SEO) 기반의 롱테일 키워드 공략.
*   **3개월차 (Retention/Community):** 커뮤니티 탭 활용 및 시청자 참여형 콘텐츠(Live/Q&A) 강화.

---

### 🛠️ 즉시 실행할 명령 (Execution Commands)

CEO님의 지시를 완수하기 위해, 저는 먼저 아래의 도구들을 순차적으로 실행하여 **'분석 근거'**를 마련하겠습니다.

```bash
# 1. 자사 채널의 최신 성과 데이터 추출
python analyze_my_channel_performance.py --period last_30_days

# 2. 경쟁 채널의 급상승 영상 및 키워드 분석
python analyze_competitors.py --targets "competitor_a, competitor_b"

# 3. 수집된 데이터를 바탕으로 3개월 로드맵 초안 생성
python generate_content_roadmap.py --input raw_data.json --output roadmap_v1.md
```

**[알림]**
위 명령어를 실행한 직후, **"데이터 기반의 3개월 콘텐츠 전략 보고서"**를 완성하여 즉시 보고드리겠습니다. 잠시만 기다려 주십시오.
