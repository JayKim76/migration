# 🔍 Researcher — 최근 경쟁사 트렌드 및 주요 데이터 분석 진행

이 지시는 **CEO(사용자)**의 전략적 의사결정인 **"최근 경쟁사 트렌드 분석"**을 수행하기 위해, 시스템 내에서 가장 적합한 에이전트를 선정하고 실행 계획을 수립하는 프로세스를 가동합니다.

현재 상황에서 이 작업을 수행하기 위해 **Researcher(Trend Analyst)** 역할을 수행할 에이전트를 선정하고, 실행 계획을 다음과 같이 제안합니다.

---

### 1. 에이전트 선정 (Agent Selection)

**주요 에이전트: `Researcher` (Trend Analyst)**
*   **선정 이유:** 현재 지시 사항의 핵심은 '경쟁사 트렌드 분석'입니다. `Researcher` 에이전트는 외부 데이터 수집, 트렌드 파악, 그리고 이를 전략적 인사이트로 변환하는 데 특화되어 있습니다.
*   **보조 에이전트: `Business Strategist` (또는 `Planner`)**
    *   **역할:** 수집된 트렌드 데이터를 바탕으로 우리 회사의 강점/약점(SWOT)을 도출하고, 실행 가능한 전략적 제언을 구조화합니다.

---

### 2. 실행 계획 (Action Plan)

지시사항을 완수하기 위해 다음과 같은 **3단계 프로세스**로 진행하겠습니다.

#### **[Step 1] 데이터 수집 및 모니터링 (Researcher)**
*   **대상:** 주요 경쟁사(직접적/잠재적)의 최근 업데이트, 신규 서비스 출시, 보도자료, 기술 블로그, SNS 반응.
*   **방법:** 
    *   최근 3개월 내의 주요 키워드(예: AI 자동화, 비용 절감, 사용자 경험 등)를 기반으로 한 웹 크롤링 및 뉴스 스크래핑.
    *   경쟁사의 기술적 변화(Tech Stack 업데이트, 신규 API 출시 등) 추적.
*   **산출물:** 경쟁사 동향 Raw Data 리포트.

#### **[Step 2] 트렌드 패턴 분석 (Researcher + Analyst)**
*   **방법:** 
    *   수집된 데이터에서 반복적으로 나타나는 '패턴'과 '키워드' 추출.
    *   경쟁사들이 공통적으로 집중하고 있는 기술적/비즈니스적 영역 식별.
    *   시장 내의 '공백 영역(White Space)' 탐색 (경쟁사들이 아직 건드리지 않은 영역).
*   **산점도 분석:** 경쟁사들의 움직임을 '기술 혁신성' vs '시장 침투력' 축으로 시각화 분석.

#### **[Step 3] 전략적 인사이트 및 실행 제언 (Business Strategist)**
*   **방법:** 
    *   **SWOT 분석:** 경쟁사 트렌드에 따른 우리의 위협(Threat)과 기회(Opportunity) 정의.
    *   **Actionable Item 도출:** "우리는 무엇을 해야 하는가?"에 대한 구체적인 실행 과제(예: 특정 기능 고도화, 신규 타겟 시장 진입 등) 제안.
*   **산출물:** **[CEO 보고용: 경쟁사 트렌드 분석 및 전략 대응 보고서]**
