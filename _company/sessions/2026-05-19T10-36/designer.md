# 🎨 Designer — 브랜드 비주얼과 디자인 요소들을 업데이트하여 데이터시스의 정체성을 강화하고, 사용자들에게 더 매력적인 경험을 제공하는 방안을 탐구해 보세요.

## 🎨 디자인 시스템 스펙: V2.0 (브랜드 정체성 강화)

제시된 브랜드 요구사항을 바탕으로, 단순한 디자인 가이드라인을 넘어 실제 개발과 디자인에 적용 가능한 **'디자인 시스템(Design System)'**의 초기 스펙을 수립합니다. 이는 향후 모든 마케팅 자료, 웹사이트, 앱 UI/UX의 일관성을 유지하는 핵심 기반이 됩니다.

---

### 📑 1. 핵심 디자인 원칙 (Design Principles)

우리가 지향하는 사용자 경험은 **신뢰성, 명료성, 미래 지향성**입니다.

1.  **Clarity First (명료성 우선):** 복잡한 데이터와 프로세스를 가장 직관적인 형태로 시각화하여 사용자가 '쉽게 이해'하도록 돕는다.
2.  **Systemic Reliability (체계적 신뢰):** 모든 컴포넌트는 일관된 규칙(Rule)에 따라 작동하며, 예측 가능한 경험을 제공한다.
3.  **Forward Motion (진행하는 동력):** '자동화'와 '진보'의 느낌을 주어, 기술적 우위와 지속적인 발전을 시각적으로 표현한다.

### 🎨 2. 시각 디자인 스펙 (Visual Specification)

#### 2.1. 컬러 팔레트 (Color Palette)

기술적 신뢰와 지성을 상징하는 **딥 블루 계열**을 메인으로, 활력과 주의를 끄는 **네온 포인트**를 보조 색상으로 사용합니다.

| 역할 | 이름 | HEX 코드 | 사용 목적 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary** | Deep Navy | `#0A1931` | 배경, 텍스트(주요), 헤더. 신뢰성 표현. | 다크 모드 기본 배경색. |
| **Secondary** | Tech Blue | `#4A90E2` | 주요 버튼, 액션 요소, 강조선. | 브랜드의 핵심 색상. |
| **Accent** | Neon Green | `#50E3C2` | 성공 상태, 활성화된 요소, 데이터 하이라이트. | 미래 지향적 포인트 컬러. |
| **Warning** | Amber | `#F5A623` | 경고 메시지, 주의 필요 지점. | |
| **Background** | Light Gray | `#F4F7FA` | 콘텐츠 영역 배경. 시각적 분리. | 라이트 모드 기본 배경. |
| **Text** | Off-Black | `#2C3E50` | 본문 텍스트. 눈의 피로도를 낮춤. | |

#### 2.2. 타이포그래피 (Typography)

가독성과 기술적인 느낌을 동시에 줄 수 있는 **산세리프 계열**을 채택합니다.

*   **메인 폰트:** Inter 또는 Pretendard (가독성, 디지털 환경 최적화)
*   **Heading (제목):** Bold, 24pt 이상. 명확하고 힘 있는 구조.
*   **Body (본문):** Regular, 16pt. 긴 텍스트에서도 피로도가 적도록 설정.
*   **Code/Data:** Monospace (예: Roboto Mono). 데이터와 코드를 명확히 분리.

### 🧱 3. 컴포넌트 라이브러리 (Component Library)

모든 UI 요소는 재사용 가능한 컴포넌트 단위로 정의합니다.

| 컴포넌트 | 정의 및 사용 규칙 | 예시 |
| :--- | :--- | :--- |
| **Button** | **Type:** Primary (Tech Blue), Secondary (Outline), Ghost (Text Only). **State:** Default, Hover, Disabled. | `[Primary] 분석 실행` |
| **Card** | 그림자(Shadow)를 최소화하고, 테두리(Border)를 사용하여 정보를 묶는다. 배경색은 Light Gray를 사용해 콘텐츠 영역과 구분. | 카드 제목, 아이콘, 텍스트 블록. |
| **Input Field** | 포커스(Focus) 시 테두리 색상을 `Tech Blue`로 변경하여 상호작용을 명확히 인지시킨다. | 검색창, 데이터 입력 필드. |
| **Iconography** | **Stroke 기반**의 라인 아이콘을 사용한다. (Solid 아이콘 사용 지양). 1pt 단위로 크기 통일. | ⚙️ (설정), 📊 (분석), 🚀 (실행). |
| **Data Visualization** | 차트나 그래프는 배경에 그리드(Grid) 라인을 은은하게 넣어 데이터의 좌표계를 명확히 한다. (색상: Accent/Warning 활용). | 시간 흐름에 따른 변화 그래프. |

### 🚀 4. 사용자 경험 (UX) 가이드라인

1.  **마이크로 인터랙션:** 버튼 클릭 시, 로딩 시작 시 등 모든 상호작용에 부드러운 **트랜지션(Transition)** 애니메이션을 적용하여 기술의 '유려함'을 강조합니다.
2.  **레이아웃 그리드:** 12컬럼 그리드를 표준으로 채택하여, 어떤 콘텐츠가 들어와도 안정적이고 균형 잡힌 구조를 유지합니다.
3.  **정보 계층 구조:** 가장 중요한 정보는 항상 **최상단에, 가장 큰 타이포그래피로** 배치하여 사용자가 정보를 찾는 노력을 최소화합니다.
