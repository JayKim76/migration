## 🎬 숏폼 영상 제작 계획서 (Short-form Production Plan)

### **[영상 컨셉: "The Future of Data Integrity"]**
*   **톤앤매너:** 테크니컬(Technical), 긴박함(Urgent), 신뢰감(Reliable), 세련됨(Sleek).
*   **핵심 메시지:** "데이터 리스크, 이제 자동화된 검증으로 종결합니다."

### **[1. 영상 스크립트 (30~45초 분량)]**

| 시간 | 화면 연출 (Visual) | 자막 (Text Overlay) | 오디오 (Voice Over/SFX) |
| :--- | :--- | :--- | :--- |
| **00-05s** | 복잡하게 엉킨 데이터 선들이 끊어지거나 에러 메시지가 뜨는 화면 (Glitch 효과) | **데이터 리스크, 아직도 수동으로 잡으시나요?** | (긴박한 사이렌 소리 또는 글리치 사운드) "데이터 오류, 아직도 수동으로 찾고 계십니까?" |
| **05-15s** | 어두운 화면에서 밝은 빛이 들어오며 `Migration Tool` 로고가 선명하게 등장 | **Migration Tool 고도화 완료!** | (빠르고 경쾌한 비트로 전환) "이제 걱정 마세요. 우리의 Migration Tool이 완벽하게 검증되었습니다." |
| **15-30s** | 데이터가 정렬되고 깔끔한 대시보드로 변하는 모션 그래픽 | **정확한 검증 + 완벽한 자동화** | "정밀한 검증과 강력한 자동화로 데이터의 무결성을 보장합니다." |
| **30-40s** | AI 에이전트가 업무를 수행하는 세련된 UI 화면 | **AI 기반의 비즈니스 리스크 관리** | "AI 에이전트와 함께하는 스마트한 리스크 관리, 지금 시작하세요." |
| **40-45s** | 회사 로고와 웹사이트 URL 등장 | **[회사 로고] 지금 확인하기** | (깔끔한 엔딩음) "비즈니스의 미래, 우리가 만듭니다." |

### **[2. BGM 및 사운드 디자인 가이드]**
*   **BGM 스타일:** **"Phonk"** 또는 **"Cyberpunk Tech"** 스타일.
    *   초반: 저음이 강조된 무겁고 긴장감 있는 베이스(Deep Bass)와 글리치(Glitch) 사운드.
    *   전환점(05s): 강력한 드롭(Drop)과 함께 비트가 빨라지는 트랩(Trap) 또는 테크노(Techno) 비트.
*   **SFX (효과음):**
    *   데이터 에러 발생 시: '삐-' 하는 고주파 경고음.
    *   도구 등장 시: '슈욱-' 하는 스위시(Swish) 사운드.
    *   데이터 정렬 시: 디지털 알림음(Digital Ping).

### **[3. 편집 가이드 (Editing Instruction)]**
*   **컷 편집:** 비트의 스네어(Snare)나 킥(Kick) 소리에 맞춰 화면 전환(Cut)을 아주 빠르게 진행할 것.
*   **색감(Color Grading):** 초반에는 다크하고 차가운 블루/그레이 톤 $\rightarrow$ 후반에는 선명하고 밝은 화이트/골드 톤으로 대비 극대화.
*   **자막 스타일:** 굵은 산세리프(Sans-serif) 체를 사용하고, 중요한 키워드에는 네온(Neon) 효과나 글리치 효과를 적용.
