# 🎨 Designer — 새로운 유튜브 채널의 브랜드 아이덴티티와 썸네일 디자인을 고민하여 전체적인 시각적 스타일을 설정하세요.

## 🎨 Visual Identity & Design System Guide

제시된 지침과 현재까지 구축된 브랜드 자산을 바탕으로, 콘텐츠 제작의 일관성과 전문성을 극대화하기 위한 **통합 비주얼 아이덴티티(Visual Identity) 및 디자인 시스템 가이드**를 수립합니다. 이 가이드는 모든 마케팅 자료, 영상 콘텐츠, 웹사이트 요소에 적용되어 브랜드 경험을 통일하는 것을 목표로 합니다.

---

### 📄 1. 브랜드 핵심 정의 (Brand Core Definition)

| 항목 | 내용 | 적용 가이드라인 |
| :--- | :--- | :--- |
| **브랜드 페르소나** | 신뢰할 수 있는, 전문적이지만 접근성이 높은, 통찰력 있는 조언자. | 지나치게 딱딱하거나 가볍지 않은 톤 앤 매너 유지. |
| **핵심 가치** | 전문성(Expertise), 투명성(Transparency), 성장(Growth). | 모든 커뮤니케이션에 데이터와 논리적 근거를 제시. |
| **톤 앤 매너** | **지적이고 차분함.** (Intellectual & Calm). 과장된 감정 표현 지양. | 전문 용어 사용 시 반드시 쉬운 비유로 설명하는 구조화 필요. |

### 🎨 2. 컬러 팔레트 (Color Palette)

컬러는 감정적 반응을 유도하는 가장 강력한 도구이므로, 주조색과 보조색의 사용 목적을 명확히 분리해야 합니다.

| 역할 | 색상 이름 | Hex Code | CMYK (인쇄용) | 사용 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary (주조색)** | Deep Navy | `#0A1931` | C90 M70 Y30 K75 | 배경, 헤더, 타이포그래피. **신뢰성** 부여. |
| **Secondary (강조색)** | Tech Teal | `#1ABC9C` | C85 M0 Y35 K0 | CTA 버튼, 핵심 데이터 하이라이트. **긍정적 변화** 상징. |
| **Accent (보조색)** | Warm Gold | `#FFC300` | C10 M20 Y100 K0 | 아이콘, 중요 수치 강조. **주의 집중** 유도. |
| **Neutral (배경/텍스트)** | Off-White | `#F9FAFB` | C1 M1 Y2 K0 | 메인 배경색. 눈의 피로도를 낮춤. |
| **Error (경고)** | Soft Red | `#E74C3C` | C10 M80 Y70 K0 | 경고, 오류 메시지. |

**✅ 컬러 사용 규칙:**
1.  **배경:** Off-White (90%) $\rightarrow$ Deep Navy (10%)
2.  **CTA (클릭 유도):** 반드시 Tech Teal을 사용하며, 충분한 대비(Contrast)를 확보해야 함.
3.  **강조:** Tech Teal과 Warm Gold는 절대 동시에 가장 큰 영역을 차지해서는 안 되며, 어느 한쪽이 다른 쪽을 받쳐주는 방식으로 사용되어야 함.

### ✒️ 3. 타이포그래피 (Typography)

가독성이 최우선이므로, 산세리프(Sans-serif) 계열의 모던한 폰트를 전면적으로 사용합니다.

| 요소 | 폰트 (예시) | 크기 (웹/인쇄) | 굵기 (Weight) | 사용 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **Headline (H1/H2)** | Pretendard, Noto Sans KR | 32px ~ 48px | Bold (700) | 콘텐츠의 주제와 섹션을 명확히 분리. |
| **Sub-Headline (H3)** | Pretendard, Noto Sans KR | 20px ~ 24px | SemiBold (600) | 소제목, 핵심 키워드 강조. |
| **Body Text (본문)** | Pretendard, Noto Sans KR | 16px ~ 18px | Regular (400) | 본문 내용. 충분한 행간(Line Height: 1.6) 확보 필수. |
| **Caption (각주/참고)** | Pretendard, Noto Sans KR | 12px ~ 14px | Light (300) | 출처, 보조 정보. |

**💡 타이포그래피 원칙:**
*   **대문자 사용 자제:** 긴 문장이나 강조 시 대문자만 과도하게 사용하면 가독성이 떨어지므로, 굵기(Bold)와 색상 변화로 강조하는 것을 원칙으로 합니다.
*   **계층 구조:** H1 $\rightarrow$ H2 $\rightarrow$ H3 순으로 크기와 굵기의 차이를 극대화하여 정보의 위계를 명확히 합니다.

### 📐 4. 레이아웃 및 그리드 시스템 (Layout & Grid System)

**규칙:** 12 컬럼 그리드 시스템(12-Column Grid System)을 표준으로 채택합니다.

1.  **여백(Whitespace):** 정보가 밀집되는 것을 가장 경계해야 합니다. 모든 요소 주변에 최소 20px 이상의 여백을 확보하여 시각적 '쉼'을 제공합니다.
2.  **모듈화:** 모든 콘텐츠 블록은 사각형 모듈 형태로 구성하며, 모듈 간의 간격(Gutter)은 일정한 간격(예: 32px)을 유지합니다.
3.  **비대칭 균형:** 시각적으로 안정감을 주면서도 지루하지 않도록, 텍스트 블록과 이미지 블록을 엇갈리게 배치하는 비대칭 구성을 활용합니다.

### 🖼️ 5. 이미지 및 비주얼 에셋 가이드라인

| 항목 | 가이드라인 | 사용 예시 |
| :--- | :--- | :--- |
| **사진 스타일** | **미니멀리즘, 콘셉트 중심.** 인물 사진은 정면을 응시하며 신뢰감을 주는 포즈를 취해야 함. | 배경을 단순화하고, 인물이나 사물에 포커스를 맞춘 고해상도 사진. |
| **일러스트레이션** | **라인 기반(Line Art) 또는 평면적(Flat Design).** 과도한 그라데이션이나 3D 효과 지양. | 개념 설명이나 프로세스 흐름도를 시각화할 때 사용. |
| **아이콘** | **통일된 두께(Stroke Weight)의 라인 아이콘.** 모든 아이콘은 동일한 굵기와 모서리 둥글림(Border Radius)을 가져야 함. | 폰트 크기 대비 적절한 크기(예: 24px)로 사용. |
