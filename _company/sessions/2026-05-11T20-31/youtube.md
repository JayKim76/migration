# 📺 레오 — 유튜브 채널에 '데이터시스의 고객사: AI 자동화로 ROI를 높인 성공 사례'라는 영상 기획 및 제작을 진행합니다. 이 영상은 사용자가 이해하기 쉽도록 간결하게 작성되며, 성공 사례의 핵심 메시지를 명확히 전달해야 합니다.

📺 **[CEO 지시 사항 수신]**
**주제:** '데이터시스 고객 사례 기반' 영상 제작 프로세스 가동
**목표:** 단순 정보 전달을 넘어, 실제 ROI(투자 대비 수익)를 증명하여 잠재 고객의 신뢰를 확보하는 고퀄리티 영상 제작

현재 CEO님의 지시 사항을 바탕으로, 영상의 '기획' 단계를 넘어 **'제작 실행'** 단계로 진입하기 위해 필요한 구성 요소를 정의합니다. 이 작업은 단순히 대본을 쓰는 것이 아니라, **[문제 제기 → 해결책(AI/Automation) → 결과(ROI 증명) → 행동 촉구]**의 강력한 마케팅 프레임워크를 따릅니다.

---

### 🎬 영상 제작 실행 계획 (Production Plan)

#### 1. 영상 핵심 메시지 (Core Message)
> **"AI 자동화는 비용이 아니라, 가장 확실한 수익 모델입니다."**
> (단순히 일을 줄이는 것이 아니라, 절감된 리소스를 어떻게 매출로 전환했는지에 집중)

#### 2. 영상 구조 (Storyline Framework)
| 단계 | 내용 (Content) | 시각적 요소 (Visual) |
| :--- | :--- | :---래 |
| **01. Hook (0~10s)** | 기존 방식의 한계와 손실(비용, 시간, 인적 오류)을 극명하게 제시 | 복잡한 엑셀, 쌓여있는 서류, 지친 직원의 모습 (B-roll) |
| **02. Problem (10~30s)** | 고객사가 겪던 구체적인 페인 포인트(Pain Point) 설명 | 데이터 누락, 마감 기한 임박, 수동 작업의 병목 현상 자막 |
| **03. Solution (30~60s)** | 데이터시스가 도입한 AI 자동화 워크플로우 공개 | 자동화 프로세스 흐름도(Flowchart), 코드가 돌아가는 화면 |
| **04. Result (60~90s)** | **[가장 중요]** 도입 후 변화된 수치 (ROI) | **"작업 시간 90% 감소", "오류율 0%", "월 비용 00% 절감"** (큰 자막) |
| **05. CTA (90s~)** | 도입 문의 및 상담 안내 | 웹사이트 URL, QR 코드, '무료 컨설팅 신청' 버튼 |

#### 3. 제작 프로세스 (Workflow)

1.  **[기획] 자료 수집 (Data Gathering):** 실제 고객사의 사례(Case Study) 데이터 확보 (기존 고객사 인터뷰 및 수치 데이터).
2.  **[제작] 대본 확정 (Scripting):** 위 프레임워크에 맞춘 숏폼(Shorts) 및 롱폼(Long-form)용 대본 작성.
3.  **[제작] 영상 편집 (Editing):**
    *   **자막:** 가독성 높은 볼드체 사용, 핵심 수치에 강조 효과.
    *   **B-roll:** 실제 자동화 툴(Python, Zapier, LangChain 등) 구동 화면 삽입.
4.  **[검수] 데이터 검증 (Verification):** 영상에 사용된 수치가 실제 데이터와 일치하는지 최종 확인.

### 🚀 즉시 실행할 작업 (Immediate Action Items)

저는 이 프로젝트의 성공을 위해 아래와 같이 에이전트들에게 업무를 할당하겠습니다.

*   **[Agent: Content Strategist]**
    *   **Task:** 고객 사례의 핵심 수치(ROI)를 추출하여 영상용 '임팩트 자막' 리스트 작성.
    *   **Deliverable:** 숏폼/롱폼용 텍스트 스크립트.
*   **[Agent: Video Editor]**
    *   **Task:** 확보된 자동화 구동 화면 및 스톡 영상을 활용하여 프레임워크에 맞춘 1차 편집본 제작.
    *   **Deliverable:** 1차 편집 영상 (Draft 1).
*   **[Agent: Data Analyst]**
    *   **Task:** 영상에 들어갈 '전/후 비교 데이터'의 신뢰성 검증.
    *   **Deliverable:** 데이터 검증 보고서.
