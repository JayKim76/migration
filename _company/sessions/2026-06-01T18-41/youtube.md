# 📺 레오 — 1일 1편의 영상을 제작하고, 유튜브 채널에 업로드하기

현재 회사의 목표는 **"1일 1영상 업로드"**라는 매우 도전적인 실행 과제를 안고 있습니다. 이를 달성하기 위해서는 단순히 영상을 만드는 것을 넘어, **'콘텐츠 기획 - 제작 - 업로드 - 최적화'**로 이어지는 파이프라인이 끊김 없이 돌아가는 **'자동화된 워크플로우'**를 구축하는 것이 핵심입니다.

현재 시스템(YouTube Agent)은 기획과 분석 도구는 갖추고 있으나, 이를 실제 영상 파일로 변환하거나 업로드하는 '물리적 실행' 단계의 연결이 필요합니다. 따라서 오늘의 최우선 과제는 **[영상 제작 프로세스의 표준화 및 자동화 파이프라인 구축]**으로 정의합니다.

---

### 🚀 오늘의 실행 계획 (Action Plan)

**1. 목표:** 1일 1영상 업로드를 위한 **'Short-form/Long-form 제작 파이프라인'**의 병목 구간 해소 및 자동화 트리거 설정

**2. 핵심 작업 (Single Task):**
*   **콘텐츠 소스 자동 추출 및 스크립트 생성 프로세스 구축:** `Trend_Analyzer`와 `Script_Writer`를 연결하여, 매일 아침 특정 시간에 뉴스/트렌드 데이터를 기반으로 한 **'오늘의 영상 스크립트'**가 자동으로 생성되어 `Draft_Folder`에 저장되도록 하는 워크플로우 설계.

**3. 담당 에이전트 및 역할 분담:**

| 담당 에이전트 | 구체적 실행 과제 (Task) | 기대 결과물 (Output) |
| :--- | :--- | :--- |
| **Trend_Analyzer** (YouTube Agent) | 유튜브 트렌드, 뉴스, 커뮤니티 핫이슈 데이터를 수집하여 '오늘의 영상 주제' 선정 | 선정된 주제 리스트 및 핵심 키워드 |
| **Script_Writer** (Content Agent) | 선정된 주제를 바탕으로 1분 내외의 숏폼(Shorts) 또는 5분 내외의 롱폼 스크립트 작성 | 완성된 영상 스크립트 (txt/md) |
| **Video_Editor** (Production Agent) | (가상/연결) 작성된 스크립트를 바탕으로 AI 영상 생성 도구(예: HeyGen, Vrew 등)와 API 연동 검토 | 영상 초안 생성 프로세스 설계도 |

---

### 📅 실행 로드맵 (Workflow)

1.  **[Phase 1: Trigger]** 매일 오전 06:00, `Trend_Analyzer`가 유튜브 API 및 뉴스 크롤링을 통해 급상승 키워드 추출.
2.  **[Phase 2: Drafting]** 추출된 키워드를 `Script_Writer`에게 전달 $\rightarrow$ 숏폼용 대본 자동 생성.
3.  **[Phase 3: Asset Prep]** 생성된 대본을 바탕으로 이미지/자막/TTS 소스 리스트 자동 생성.
4.  **[Phase 4: Review & Publish]** 관리자(사용자)의 최종 컨펌(또는 자동 승인 규칙 적용) 후 유튜브 API를 통해 `Unlisted` 상태로 업로드 예약.

---

### 🚩 기대 효과
*   **지속 가능성 확보:** 사람이 매번 주제를 고민하는 '의사결정 피로도'를 제거하여 1일 1영상 루틴을 강제함.
*   **콘텐츠 품질의 균일화:** 검증된 트렌드 데이터를 기반으로 제작되므로 조회수 확보 가능성 증대.
*   **확장성:** 향후 영상 제작 자동화 툴(API) 연동 시 즉각적인 Scale-up 가능.
