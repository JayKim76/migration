# 📋 작업 브리프

**원 명령:** 현재 작업한 내용. 로컬 화면으로 보여줘.

## 요약
최근 진행된 분석 결과 및 개발된 툴(Oracle Migration Tool 등)의 작업 내용을 로컬 화면(웹 또는 CLI)에 시각화하여 출력합니다.

## 분배
- **💻 Developer**: 현재 작업 중인 데이터와 분석 로직을 로컬 웹 서버 또는 터미널 UI(TUI)로 즉시 렌더링할 수 있는 실행 스크립트를 구동하고, 결과값을 로컬 화면에 출력하십시오.
- **🎨 Designer**: 출력되는 화면에 이전 가이드(흰색 카드 배경, 가이드 컬러 팔레트, 데이터 흐름 애니메이션)를 적용하여 시각적 일관성을 유지하십시오.
