# 🎨 Designer — 사업팀이 정의한 플로우와 메시지를 바탕으로, 랜딩 페이지의 와이어프레임과 디자인 시스템을 구축해주세요. 히어로 섹션, 기능 소개 섹션, CTA(Call-to-Action) 버튼 등 각 요소의 비주얼 가이드라인(컬러, 타이포, 이미지 배치)을 제공해야 합니다.

🎨 Designer: 작업 시작합니다.

CEO 지시에 따라, 사업팀에서 정의한 **KPI 중심의 사용자 플로우(User Flow)**를 완벽하게 지원하는 랜딩 페이지 디자인 시스템과 와이어프레임 가이드라인을 구축했습니다. 이 디자인은 단순히 예쁜 페이지가 아니라, 사용자를 **설득하고, 신뢰를 구축하며, 최종적으로 CTA(Trial Sign-up)**로 유도하는 '전환 장치'로서의 역할을 수행합니다.

## 🖼️ 1. 디자인 시스템 정의 (Design System Foundation)

랜딩 페이지 전체에 일관성을 부여하고, 사용자의 시선을 원하는 곳으로 유도하기 위한 기본 규칙을 정의합니다.

### 🎨 컬러 팔레트 (Color Palette)
| 역할 | 색상 (Hex Code) | 용도 및 의도 |
| :--- | :--- | :--- |
| **Primary (신뢰)** | `#004A99` (딥 블루) | 배경, 주요 제목, 브랜드 로고. 신뢰성, 안정감을 구축합니다. |
| **Secondary (보조)** | `#E6F0FF` (라이트 블루) | 배경 분할, 섹션 구분. Primary 색상을 부드럽게 반복하여 지루함을 방지합니다. |
| **Accent (액션/CTA)** | `#FF6B3D` (오렌지-코랄) | **가장 중요한 버튼, 하이라이트, 경고 메시지**. 시각적 대비를 극대화하여 사용자의 행동을 즉각적으로 유도합니다. |
| **Neutral (텍스트)** | `#333333` (다크 그레이) | 본문 텍스트, 설명글. 순수 블랙보다 부드러워 장문 가독성을 높입니다. |
| **Background** | `#FFFFFF` (화이트) | 기본 배경. 깔끔하고 전문적인 느낌을 유지합니다. |

### 🅰️ 타이포그래피 시스템 (Typography System)
*   **헤드라인 (H1, H2):** Pretendard Bold / SemiBold
    *   *규칙:* 크고 과감하며, 문제의 심각성(Pain Point)을 강조하는 역할을 합니다. (최대 48px, 32px 등)
*   **본문 (Body):** Pretendard Regular / Medium
    *   *규칙:* 가독성이 최우선입니다. 16px 이상을 유지하여 장시간 읽어도 피로도가 낮아야 합니다.
*   **CTA 버튼:** Pretendard Bold (대문자 권장)
    *   *규칙:* 간결하고 명확하게 행동을 지시하는 문구만 사용합니다.

### 🖼️ 이미지 및 비주얼 레퍼런스
*   **스타일:** 추상적 데이터 시각화 (Abstract Data Viz) 또는 미니멀한 사용자 인터페이스(UI) 스크린샷을 활용합니다.
*   **배치:** 텍스트가 주도권을 가지며, 이미지는 **메시지를 보강하는 증거(Proof)**의 역할에 머물러야 합니다. (예: "이런 문제를 해결했습니다" $\rightarrow$ [Before/After 시각적 비교])

## 🧩 2. 핵심 컴포넌트 가이드라인 (Component Library)

재사용성이 높은 3가지 핵심 요소를 정의합니다.

### 🚀 A. CTA 버튼 (Call-to-Action Button)
| 타입 | 색상 | 폰트 | 크기 | 배치 원칙 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary (최종)** | `#FF6B3D` (Accent) | Bold | 18px (높이 56px) | **섹션의 끝, 혹은 플로우의 핵심 전환점**에 배치하여 '다음 행동'을 명확히 지시합니다. |
| **Secondary (탐색)** | `#004A99` (Primary) | Medium | 16px (높이 48px) | 정보 탐색이 필요한 섹션(예: '자세히 알아보기'). Primary 버튼 대비 톤 다운되어 심리적 부담이 적습니다. |
| **Ghost (보조)** | 투명 배경, `#004A99` 테두리 | Medium | 16px (높이 48px) | 부차적인 정보 제공 시 사용. 시각적 방해를 최소화합니다. |

### 📄 B. 헤드라인 구조 (Headline Structure)
*   **H1 (Hero Title):** 문제점 인식 + 우리의 가치 제안을 결합한, **가장 강력한 한 문장**. (예: "더 이상 수동적인 마케팅에 시간 낭비하지 마세요.")
*   **H2 (섹션 제목):** 플로우의 단계 목표를 명시합니다. (예: "왜 기존 방식으로는 해결이 불가능했을까요?")
*   **H3 (소제목):** 특정 기능이나 장점 하나를 집중적으로 설명할 때 사용합니다. (예: "자동화된 리포트 분석 기능")

### 💬 C. 신뢰 구축 블록 (Social Proof Block)
*   **구조:** [고객 로고 배열] $\rightarrow$ [구체적 성과 제시] $\rightarrow$ [후기 텍스트]
*   **디자인:** 배경을 Secondary 컬러로 처리하여, **이 섹션의 중요도를 높이고** 다른 섹션과 명확히 분리합니다.
*   **포인트:** 단순히 "좋아요"가 아니라, **KPI와 연결된 수치**를 반드시 포함합니다. (예: "OO사, **전환율 35% 증가** 달성")

## 📐 3. 랜딩 페이지 와이어프레임 블루프린트 (Funnel Mapping)

사업팀의 4단계 플로우에 따라 위 컴포넌트들을 배치합니다.

### 📍 1. 히어로 섹션 (Hero Section) - [Hooking & Solution]
*   **목표:** 사용자의 Pain Point에 공감하고, JAY CORP가 유일한 해결책임을 각인시킨다.
*   **배치:** 배경은 깨끗한 화이트. 텍스트가 압도적으로 크게 배치.
*   **요소 구성:**
    1.  **H1 (Pain Point 강조):** 가장 충격적이고 공감 가는 질문 또는 주장.
    2.  **서브 카피:** 문제의 심각성을 뒷받침하는 짧은 설명.
    3.  **핵심 비주얼:** 문제 상황을 암시하는 미니멀한 그래프 또는 UI 스케치.
    4.  **Primary CTA:** 눈에 띄는 오렌지-코랄 버튼. (예: "지금 무료 트라이얼 시작하기")

### 📍 2. 문제 심층 분석 섹션 (Pain Point Deep Dive) - [Hooking]
*   **목표:** 사용자가 "맞아, 나도 저랬지"라고 고개를 끄덕이게 만든다.
*   **배치:** 배경을 라이트 블루(`Secondary`)로 변경하여 섹션 분리.
*   **요소 구성:**
    1.  **H2:** (예: "왜 기존의 방식은 한계에 부딪혔을까요?")
    2.  **3~4가지 Pain Point 리스트:** 아이콘과 함께 짧은 문장으로 나열. (각 포인트는 실패 사례나 통계 데이터로 뒷받침)

### 📍 3. 핵심 기능 소개 섹션 (Feature/Solution) - [Solution]
*   **목표:** JAY CORP의 방법론(Solution)이 Pain Point를 어떻게 완벽하게 해결하는지 보여준다.
*   **배치:** 배경은 화이트. 기능별로 3단 그리드 레이아웃을 사용.
*   **요소 구성:**
    1.  **H2:** (예: "JAY CORP의 독점 알고리즘이 작동하는 방식")
    2.  **기능 블록 1, 2, 3:**
        *   [기능 이름 (H3)] $\rightarrow$ [설명 텍스트] $\rightarrow$ **[실제 작동하는 UI 스크린샷 (가장 중요)]**
    3.  **비주얼 강조:** 각 기능 소개마다 'Before (문제)'와 'After (해결)'의 대비를 명확한 비주얼로 보여준다.

### 📍 4. 신뢰 구축 및 증거 섹션 (Social Proof & Case Study) - [Proof]
*   **목표:** 추상적인 약속을 구체적인 성공 사례로 전환하여 신뢰도를 최고조로 올린다.
*   **배치:** 배경을 라이트 블루(`Secondary`)로 변경.
*   **요소 구성:**
    1.  **H2:** (예: "이미 수많은 기업이 성장을 경험하고 있습니다.")
    2.  **[핵심 고객사 3~4개] 로고 배열:** (가장 상단에 배치)
    3.  **Case Study 카드:** 고객사 이름, **가장 중요한 성과 수치(KPI)**, 짧은 인용구 순서로 구성. (예: "OO사 / 3개월 만에 전환율 35% 증가")

### 📍 5. 최종 CTA 섹션 (Closing CTA) - [Action]
*   **목표:** 모든 설득 과정이 끝난 후, 망설임을 없애고 행동을 유도한다.
*   **배치:** 배경을 Primary 블루(`Deep Blue`)로 변경하여 깊은 인상을 남긴다.
*   **요소 구성:**
    1.  **H2:** 강력한 최종 독려 문구. (예: "성공은 결심부터 시작됩니다. 지금, 변화를 시작하세요.")
    2.  **보조 카피:** 위험 부담을 최소화하는 문구 추가. (예: "신용카드 정보 필요 없음. 7일간 무료 체험.")
    3.  **Primary CTA (최대 크기):** 오렌지-코랄 버튼. (가장 크고, 가장 눈에 띄게)
